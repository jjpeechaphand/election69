## รอบตรวจข้อมูลกับเว็บ กกต. และปรับการใช้งาน (3 พ.ย. 2569 ภาคค่ำ)

- [x] **ตรวจความสะอาดและข้อมูลขาด**: ไม่มีค่าขาด ค่าติดลบ ชื่อเขตว่าง ผู้มาใช้สิทธิเกินผู้มีสิทธิ หมายเลข/รหัสผู้สมัครซ้ำ พรรคที่ไม่รู้จัก ช่องว่างแฝงหรือ Unicode ไม่ปกติในชื่อ หรือคะแนนสูงสุดเสมอกัน; ผลรวมคะแนนผู้สมัคร = บัตรดีทุกเขต พบเฉพาะความไม่ลงตัวในตัวเลขที่ กกต. ประกาศเอง: บัตรดี + บัตรเสีย + ไม่เลือกใคร ≠ ผู้มาใช้สิทธิ 17 เขต (บัตรแบ่งเขต ต่าง 1–3 ใบ) และ 12 เขต (บัญชีรายชื่อ ต่าง 1 ใบ), ผู้มาใช้สิทธิสองบัตรไม่เท่ากัน 104 เขต, ผู้สมัครได้ 0 คะแนน 3 คน — คงค่าต้นทางไว้ ไม่แก้ แต่แสดงหมายเหตุในแผงเขตที่เกี่ยวข้องและในการตรวจสอบภายใน

## การตัดสินใจสำคัญ
1. **ภาพบุคคล** การ์ดพรรคใช้ภาพแคนดิเดตนายกฯ/ตัวแทนพรรค 10 ภาพ และไม่แสดงภาพผู้นำพรรคแทนผู้ชนะรายเขต; เดิมไม่เก็บภาพ สส. รายเขตเพราะมีเพียงบางส่วน (`assets/constituents/` 189 ไฟล์ ยังไม่ใช้) แต่ตั้งแต่ 7 พ.ย. 2569 ผู้ใช้ขอภาพทุกคน จึงดึงภาพทางการของผู้สมัครแบบแบ่งเขตครบทุกคนที่ กกต. มีภาพ (3,489/3,491) แล้วไดคัตในกรอบเดียวกับภาพหัวหน้าพรรค ความครอบคลุมจึงเท่ากันทุกเขต
2. **ป้ายแผนที่** แสดงชื่อเต็มทุกจังหวัดตลอด (ตามคำขอรอบปรับภาพลักษณ์) ตัดบรรทัดตามขอบคำจากตาราง BREAKS ที่ตรวจกับทะเบียน กกต. แล้ว ชื่อยาวใช้ขนาดเล็กลงได้ถึง 8.5px แทนการใช้อักษรย่อ
3. **tooltip** เปิดห่างจากเมาส์ 18px และเลื่อนตามเมาส์ (ตามคำขอรอบล่าสุด แทนการวางข้างการ์ดแผนที่) เมื่อเมาส์หยุดจะหยุดตามเพื่อให้เข้าไปเลื่อนรายชื่อได้; คีย์บอร์ดยังวาง tooltip ข้างช่องที่โฟกัส
4. **ความหมายตัวกรอง** ภูมิภาค = ตัวกรองจริง (ตัดเขต), พรรค/จังหวัด = ไฮไลต์ (ไม่ตัดข้อมูล), ช่วงลาก = ชุดย่อยที่ลาก tooltip จังหวัดแสดงผลทั้งจังหวัดเสมอ
5. **ที่นั่ง** กราฟ A แสดงผลระดับประเทศเสมอ เพราะบัญชีรายชื่อจัดสรรระดับประเทศ
6. **อัตราการใช้สิทธิ** ใช้ยอดผู้มาใช้สิทธิของบัตรแบบแบ่งเขต (ECT stats_cons) Σตัวเศษ ÷ Σตัวส่วน
7. **บัตรเสีย** แสดงแยก แบบแบ่งเขต / บัญชีรายชื่อ ไม่รวมกัน

## ข้อจำกัดที่ยังมี
- ยังไม่มีผลทดสอบกับผู้ใช้จริง (ไม่ได้สร้างหลักฐาน usability ขึ้นเอง) — ดู `USABILITY_PROTOCOL.md`
- ทดสอบอัตโนมัติด้วย Chrome เท่านั้น (หน้ามือถือทดสอบด้วย Chrome จำลองจอสัมผัส) ยังไม่ได้ทดสอบ Firefox/Safari และอุปกรณ์สัมผัสจริง
- หน้ามือถือ: แผนที่ประเทศไทยแบบหกเหลี่ยมบนจอ 360–430 px ชื่อจังหวัดยังเล็ก (8.5–9 px ตามข้อกำหนดให้แสดงชื่อเต็มทุกจังหวัด) ตั้งแต่ 13 พ.ย. 2569 กดปุ่ม “แตะค้างแล้วเลื่อนนิ้ว” เพื่อเปิดแว่นขยาย แล้วแตะค้างและเลื่อนนิ้วเพื่ออ่านและเล็ง หรือถ่างนิ้วซูม; แนวนอนบนโทรศัพท์แผนที่ทั้งประเทศเล็กเพราะประเทศไทยเป็นรูปยาว; แว่นขยายยังไม่ได้ทดสอบกับนิ้วจริงบนโทรศัพท์
- จอโทรศัพท์เล็กที่สุด 320 × 568: แถวปุ่มรีเซ็ต/ซูมมุมขวาบนทับมุมภาคเหนือของแผนที่ประเทศไทย (เชียงราย น่าน และจังหวัดข้างเคียง) เพราะแผนที่สูงเต็มแถบ พบระหว่างทดสอบรอบปุ่มแว่นขยาย มีมาก่อนรอบนี้ ยังไม่ได้แก้ (จอ 360 × 780 ขึ้นไปไม่ทับ)
- ชื่อพรรคและชื่อบุคคลคงเป็นภาษาไทยในโหมดอังกฤษ (ไม่มีชื่อทางการภาษาอังกฤษในข้อมูล กกต. ที่มี)
- ชื่อจังหวัดภาษาอังกฤษมาจากตารางของ Thailand Hex Map (สะกดแบบ GADM เช่น Buri Ram, Si Sa Ket) ไม่ใช่ชุดชื่อทางการของ กกต.
- ในชุดข้อมูลนี้ไม่มีเขตที่คะแนนเสมอหรือข้อมูลขาด (ยืนยันซ้ำกับเว็บ กกต. 3 พ.ย. 2569) ระบบรองรับสถานะ "ยังไม่ระบุผู้ชนะ/ข้อมูลไม่ครบ" ในโค้ด แต่ทดสอบได้เฉพาะผ่าน unit test ของชั้นข้อมูล ไม่ใช่ข้อมูลจริง
- ตัวเลขที่ กกต. ประกาศเองไม่ลงตัวในบางเขต (บัตรดี + บัตรเสีย + ไม่เลือกใคร ≠ ผู้มาใช้สิทธิ 17 เขตสำหรับบัตรแบ่งเขต และ 12 เขตสำหรับบัญชีรายชื่อ ต่าง 1–3 ใบ) หน้าเว็บแสดงตามที่ประกาศและติดหมายเหตุ ไม่ปรับตัวเลขเอง
- แผนที่รายเขตใช้ขอบเขตโดยประมาณจากชุดข้อมูลชุมชน (Kittapat Ratanaphupha) ไม่ใช่แผนที่ทางการของ กกต.
- ตาราง party ของ กกต. ระบุคะแนนแบ่งเขต 0 สำหรับ 3 พรรคเล็ก (รักษ์ธรรม, รวมพลัง, สัมมาธิปไตย) ขณะที่ผลรายเขตมีคะแนน ระบบแสดงความต่างนี้ในการตรวจสอบภายใน ไม่แก้ข้อมูลต้นทาง
- ข้อมูลมีสองชุด: โปรเจกต์ในเครื่อง (`dist/data/`) กับ repository บน GitHub ไม่ซิงก์กันเอง ต้องเลือกแก้ที่เดียวเป็นหลัก หรืออัปโหลดไฟล์ที่แก้ขึ้นไปซ้ำ
