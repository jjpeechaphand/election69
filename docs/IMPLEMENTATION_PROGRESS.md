## รอบกราฟ "ใครชนะใคร" (7 พ.ย. 2569 ดึก)
ผู้ใช้เห็นว่ากราฟ "เขตเลือกตั้งต่าง ๆ ชนะกันสูสีมากน้อยแค่ไหน?" (ฮิสโทแกรมส่วนต่าง) อ่านไม่ออกและไม่มีประโยชน์ ให้คิดหัวข้อและกราฟใหม่ที่ไม่ซ้ำ (ตรวจในเครื่องแล้ว อัปโหลดขึ้น GitHub Pages 8 พ.ย. 2569)
- [x] สำรวจข้อมูลก่อนเลือก (`scratchpad` explore-rivals): ทุกเขตมีผู้ชนะและอันดับสอง 35 คู่พรรค คู่ชิงที่พบบ่อยที่สุด ภูมิใจไทย–ประชาชน 119 เขต (ภูมิใจไทยชนะ 83) ประชาชนได้ที่สอง 140 เขต แต่ละภาคต่างกันชัด → หัวข้อ **ใครชนะใคร** ตอบว่าใครคือคู่แข่งหลัก ซึ่งหน้าอื่นไม่บอก
- [x] `e69-analysis.js`: กราฟ B ใหม่ `drawRivals` เป็นแผนภาพการไหล Sankey (เขียนเองบน d3 core ไม่เพิ่มไลบรารี) ซ้าย = พรรคผู้ชนะ ขวา = พรรคอันดับสอง แถบไล่สีจากพรรคหนึ่งไปอีกพรรค พรรคเล็กรวมเป็น "พรรคอื่น" ป้ายไม่ทับกัน ตัวเลขในแถบที่หนาพอ; คลิกแถบ = เลือกชุดเขต (brush source `rivals`) คลิกพรรค = ไฮไลต์พรรค; ข้อค้นพบเปลี่ยนตามภาคและพรรค; มุมมองตารางทุกคู่พร้อมส่วนต่างมัธยฐาน; ลบโค้ดฮิสโทแกรม (`marginSetup`, `drawMargin`, `brush-preset`, `marginMetric`) ปุ่ม "ล้างช่วง" เป็น "ล้างการเลือก"; แท็บมือถือ "ใครชนะใคร"

## การตัดสินใจสำคัญ
1. **ภาพบุคคล** การ์ดพรรคใช้ภาพแคนดิเดตนายกฯ/ตัวแทนพรรค 10 ภาพ และไม่แสดงภาพผู้นำพรรคแทนผู้ชนะรายเขต; เดิมไม่เก็บภาพ สส. รายเขตเพราะมีเพียงบางส่วน (`assets/constituents/` 189 ไฟล์ ยังไม่ใช้) แต่ตั้งแต่ 7 พ.ย. 2569 ผู้ใช้ขอภาพทุกคน จึงดึงภาพทางการของผู้สมัครแบบแบ่งเขตครบทุกคนที่ กกต. มีภาพ (3,489/3,491) แล้วไดคัตในกรอบเดียวกับภาพหัวหน้าพรรค ความครอบคลุมจึงเท่ากันทุกเขต
2. **ป้ายแผนที่** แสดงชื่อเต็มทุกจังหวัดตลอด (ตามคำขอรอบปรับภาพลักษณ์) ตัดบรรทัดตามขอบคำจากตาราง BREAKS ที่ตรวจกับทะเบียน กกต. แล้ว ชื่อยาวใช้ขนาดเล็กลงได้ถึง 8.5px แทนการใช้อักษรย่อ
3. **tooltip** เปิดห่างจากเมาส์ 18px และเลื่อนตามเมาส์ (ตามคำขอรอบล่าสุด แทนการวางข้างการ์ดแผนที่) เมื่อเมาส์หยุดจะหยุดตามเพื่อให้เข้าไปเลื่อนรายชื่อได้; คีย์บอร์ดยังวาง tooltip ข้างช่องที่โฟกัส
4. **ความหมายตัวกรอง** ภูมิภาค = ตัวกรองจริง (ตัดเขต), พรรค/จังหวัด = ไฮไลต์ (ไม่ตัดข้อมูล), ช่วงลาก = ชุดย่อยที่ลาก tooltip จังหวัดแสดงผลทั้งจังหวัดเสมอ
5. **ที่นั่ง** กราฟ A แสดงผลระดับประเทศเสมอ เพราะบัญชีรายชื่อจัดสรรระดับประเทศ
6. **อัตราการใช้สิทธิ** ใช้ยอดผู้มาใช้สิทธิของบัตรแบบแบ่งเขต (ECT stats_cons) Σตัวเศษ ÷ Σตัวส่วน
7. **บัตรเสีย** แสดงแยก แบบแบ่งเขต / บัญชีรายชื่อ ไม่รวมกัน

- ชื่อพรรคและชื่อบุคคลคงเป็นภาษาไทยในโหมดอังกฤษ (ไม่มีชื่อทางการภาษาอังกฤษในข้อมูล กกต. ที่มี)

- ในชุดข้อมูลนี้ไม่มีเขตที่คะแนนเสมอหรือข้อมูลขาด (ยืนยันซ้ำกับเว็บ กกต. 3 พ.ย. 2569) ระบบรองรับสถานะ "ยังไม่ระบุผู้ชนะ/ข้อมูลไม่ครบ" ในโค้ด แต่ทดสอบได้เฉพาะผ่าน unit test ของชั้นข้อมูล ไม่ใช่ข้อมูลจริง
