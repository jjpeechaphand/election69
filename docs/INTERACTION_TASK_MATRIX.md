# ตารางการโต้ตอบ × งานวิเคราะห์ (Interaction–Task Matrix)

ประเภทการโต้ตอบตาม vis-10 p.5 (Select, Explore, Reconfigure, Encode, Abstract/Elaborate, Filter, Connect) ทุกแถวคือฟังก์ชันที่ทำงานจริงและมีการทดสอบใน `tests/two-page.e2e.cjs` (เดสก์ท็อป) หรือ `tests/phone.e2e.cjs` (โทรศัพท์) เว้นแต่ระบุไว้

## ตามเทคนิค
| ประเภท | การโต้ตอบในระบบ | ตำแหน่ง |
|---|---|---|
| **Select** | คลิกการ์ดพรรค/แท่งพรรค/legend → ไฮไลต์พรรคทุกมุมมอง (การ์ดอื่นจาง แผนที่เปลี่ยนสีเป็นคลื่นจากฐานเสียงของพรรค กราฟละลายเข้าภาพใหม่); คลิกจังหวัด → ปักหมุดแผงจังหวัด; คลิกเขต/จุด/แถว → เลือกเขต (วงแหวน แถบของคู่ชิงที่มีเขตนั้นมีเส้นขอบ แถวสีฟ้า) เลือกจากค้นหาหรือรายการแล้วเขตบนแผนที่กระเพื่อม | ทั้งสองหน้า |
| **Explore** | แพน/ซูมแผนที่ (เมาส์ ล้อ ปุ่ม + − รีเซ็ต, สองนิ้วบนมือถือ); tooltip เปิดที่เมาส์และเลื่อนตาม เป็นบทสรุปสั้น คลิกเพื่อดูผลทุกเขต; ปุ่มลูกศรเลื่อนระหว่างจังหวัด; หน้าวิเคราะห์: ภาพย่อ 4 กราฟพร้อมกัน ชี้จุดในภาพย่อเห็น tooltip | แผนที่, วิเคราะห์ |
| **Focus + context** (13 พ.ย. 2569, โทรศัพท์เท่านั้น) | แผนที่ประเทศไทยบนโทรศัพท์: กดปุ่ม “แตะค้างแล้วเลื่อนนิ้ว” (สวิตช์เปิด/ปิด ถ้าไม่เปิด แผนที่ทำงานแบบปกติ) แล้วแตะค้าง (≈0.17 วินาที) หรือแตะแล้วเลื่อนนิ้ว → แว่นขยายแบบ fisheye ใต้นิ้ว จังหวัดใต้นิ้วขยายกว้างประมาณหนึ่งนิ้วโป้ง (≈78 px, 2–3 เท่า) จังหวัดรอบ ๆ ขยายลดหลั่น จังหวัดไกลออกไปถูกเบียดเล็กน้อยแต่ยังเห็นครบทั้งประเทศ; ป้ายเหนือจังหวัดบอกชื่อ จำนวนเขต พรรคที่ชนะ และ "ปล่อยนิ้วเพื่อเปิดจังหวัดนี้"; เลื่อนนิ้วแล้วแว่นตามไปจังหวัดถัดไป ปล่อยนิ้ว → เปิดจังหวัดนั้น ปล่อยบนทะเล → ยกเลิก; สองนิ้ว → ซูมตามปกติ; แตะสั้นยังเปิดจังหวัดเหมือนเดิม | แผนที่ (โทรศัพท์) |
| **Abstract/Elaborate (ซูมเชิงความหมาย)** | คลิกจังหวัด → กล้องบินเข้าแล้วช่องหกเหลี่ยมบานเป็นขอบเขตเลือกตั้งจริงของจังหวัดนั้น (เลขเขตบนแผนที่ ชี้เพื่อดูชื่ออำเภอ/เขตในเขตนั้นและผล); รีเซ็ตหรือ "แผนที่ประเทศไทย" → เขตพับกลับ กล้องถอยออก จังหวัดอื่นกลับมาเป็นระลอก; หน้าวิเคราะห์ (12 พ.ย. 2569): คลิกภาพย่อ → กราฟนั้นขยายออกจากตำแหน่งเดิมพร้อมคำถาม ข้อค้นพบ ตัวเลือก และตาราง "กลับไปภาพรวม 4 กราฟ" หรือ Esc → หดกลับเข้าที่ ทรานสิชันแสดงว่ามุมมองใหม่มาจากตรงไหน (ปิดเมื่อผู้ใช้ตั้งค่าลดการเคลื่อนไหว) | แผนที่, วิเคราะห์ |
| **Reconfigure** | จัดอันดับผู้สมัครใหม่ 5 แบบ (คะแนนมากที่สุด/ชนะขาด/ชนะเฉียดฉิว/แพ้ทั้งที่คะแนนสูง/ชนะด้วยคะแนนน้อย) และเลือกจำนวนแถว 10/20/50; เรียงที่นั่งในรูปสภาใหม่ให้พรรคที่เลือกมาอยู่ติดกันทางซ้าย; ปุ่มฝ่ายรัฐบาล/ฝ่ายค้านเรียงที่นั่งของฝ่ายนั้นเข้ารูปสภา; เรียงแถวฮีตแมปตามพรรคที่เลือก | วิเคราะห์ |
| **Encode** | สีแผนที่ 5 แบบในสามกลุ่ม (ที่นั่ง: พรรคชนะ; คะแนนเสียง: คะแนนเลือกพรรค, คะแนนเลือกผู้สมัคร — ไม่เลือกพรรค = พรรคที่ได้คะแนนบัตรนั้นมากสุด, เลือกพรรค = ความเข้มตามสัดส่วน; การใช้สิทธิ: ใช้สิทธิ, บัตรเสีย), ชั้นที่นั่ง เขต/บัญชีรายชื่อ/ทั้งสภา ในกราฟกระจาย A, ความเข้มของสีพรรคบอกอันดับในกราฟ D (ชนะ ที่สอง ที่สาม เทา = อันดับ 4 ลงไป), จุดทึบ/จุดจางในรูปสภา (พรรคที่เลือก/ยังไม่เลือก), ตัวชี้วัดฮีตแมป 4 แบบ, กราฟ ↔ ตาราง | ทั้งสองหน้า |
| **Abstract/Elaborate** | hover → tooltip จังหวัด → คลิกปักหมุด (ผู้ชนะทุกเขตพร้อมภาพ) → คลิกเขต → ผู้ชนะภาพใหญ่ อันดับสองพร้อมส่วนต่าง และผู้สมัครทุกคนพร้อมภาพ + คะแนนสองใบ; อันดับผู้สมัคร → คลิกแถว → ผลทั้งเขต; ชี้จุดในรูปสภา → ที่นั่งของพรรคและผลรวมถ้าเพิ่มหรือเอาออก; การ์ดฝ่ายรัฐบาล/ฝ่ายค้าน → ทุกพรรคของฝ่ายนั้นพร้อมจำนวน ส.ส. และระยะจากครึ่งสภา; รายชื่อพรรคในรูปสภา → "อีก N พรรค" กางพรรคเล็กทั้งหมด; ฮีตแมปภูมิภาค → รายจังหวัด; ตารางเทียบเขต → "ดูผลทั้งเขต"; ชี้จังหวัดบนแผนที่ → ช่องยกตัวขึ้น + สรุป | ทั้งสองหน้า |
| **Filter** | ตัวกรองภูมิภาค (ตัดเขตในกราฟ B, D อันดับของแต่ละพรรค, ฮีตแมป และอันดับผู้สมัคร ยกเว้นกราฟ A, C และรวมเสียงตั้งรัฐบาล ที่ระบุว่าเป็นผลระดับประเทศ เพราะบัญชีรายชื่อและที่นั่งทั้งสภาจัดสรรทั้งประเทศ); ตัวกรองจังหวัดและพรรคจำกัดอันดับผู้สมัคร; คลิกแถบในกราฟใครชนะใคร → เลือกเฉพาะเขตของคู่ชิงนั้น (เช่น "ภูมิใจไทย ชนะ ประชาชน 83 เขต"); คลิกช่วงของแท่งในกราฟอันดับ → เลือกเขตชุดนั้น (เช่น "ประชาชน ได้ที่สอง" 140 เขต); บนโทรศัพท์ตัวกรองอยู่แผงเดียวกับค้นหา (แท็บ "ค้นหา/กรอง" มีตัวเลขบอกจำนวนตัวกรองที่ใช้อยู่) | ทั้งสองหน้า |
| **Connect** | เขตที่เลือกจากแถบคู่ชิงหรือจากช่วงของแท่งอันดับ จำกัดอันดับผู้สมัครให้เหลือเฉพาะเขตชุดนั้น แสดงเป็นชิปบนแถบบน และเปิดรายชื่อเขตได้; พรรคที่เลือก (จากการ์ด แถบด้านข้าง หรือคลิกจุด/เส้น/แถบ/ชื่อในกราฟ A B C D ที่ขยายแล้ว) เปลี่ยนสีแผนที่ ฮีตแมป ไฮไลต์ในภาพย่อและกราฟทั้งสี่ (A จุด, B แถบคู่ชิง, C เส้น, D แท่ง) มีวงขอบรอบที่นั่งของพรรคนั้นในรูปสภา และทำให้อันดับผู้สมัครเหลือเฉพาะผู้สมัครของพรรคนั้น; ชี้ชื่อพรรคในรายการของรูปสภา ↔ ที่นั่งของพรรคนั้นในรูปสว่างขึ้นพร้อมกัน; ค้นหาผู้สมัครหรือชื่อพื้นที่ → เขต → จังหวัดบนแผนที่; ช่องค้นหาในแท็บเปรียบเทียบใช้ดัชนีเดียวกัน (พื้นที่ เขต ผู้สมัคร) → เพิ่มเขตเข้าตาราง | ทั้งสองหน้า |

## ความหมายของสถานะ (ไม่ให้กราฟเปลี่ยนแบบคาดไม่ถึง)
| สถานะ | ผล | แสดงที่ |
|---|---|---|
| ตัวกรองร่วม: ภูมิภาค | **ตัดข้อมูล** เขตนอกภูมิภาคไม่ถูกนับใน KPI/กราฟ B/อันดับผู้สมัคร; แผนที่จาง (กราฟ A C D เป็นผลระดับประเทศ จึงแจ้งท้ายการ์ดว่าตัวกรองไม่ใช้) | ชิป "ตัวกรอง" |
| ไฮไลต์: พรรค | **ไม่ตัดข้อมูล** เน้นเขต/จังหวัดที่พรรคชนะ; tooltip ยังแสดงผลครบทั้งจังหวัด และแสดง "0 เขต" ถ้าพรรคไม่ชนะในจังหวัดนั้น | ชิป "ไฮไลต์" |
| เลือก: จังหวัด/เขต | ปักหมุดรายละเอียด, วงแหวน/ตัวชี้ในกราฟ | ชิป "เลือก", breadcrumb |
| ช่วงที่ลาก (brush) | ชุดย่อยเขต ใช้กับกราฟในหน้าวิเคราะห์ ดูรายชื่อได้ | ชิป "ช่วงที่ลาก" |
| Hover | ชั่วคราว ไม่เปลี่ยนสถานะ | tooltip, วงแหวนฟ้า |
| ควบคุมเฉพาะกราฟ | เรียง/หน่วย/สเกล มีผลเฉพาะกราฟนั้น อยู่ในกราฟที่ขยายแล้วเท่านั้น (ภาพย่อไม่มีตัวเลือก) | แถวปุ่มในการ์ด |
| **Clear All** | ล้างทุกอย่างข้างบน + ซูมแผนที่ + รายการเปรียบเทียบ + แผงรายละเอียด + กราฟที่ขยาย กลับหน้าภาพรวม คงภาษา | แถบด้านข้าง; บนโทรศัพท์ในแผง "ค้นหา/กรอง" |
| **อัปเดตข้อมูล** | อ่านไฟล์ข้อมูลใหม่ (ไม่ใช้แคช) วาดใหม่ในที่เดิมโดยคงทุกสถานะข้างบน ตัดเฉพาะสิ่งที่ไม่มีในข้อมูลใหม่แล้ว แจ้งจำนวนเขตที่เปลี่ยน แสดงเวลาที่โหลดล่าสุด ข้อมูลผิดไม่ถูกนำมาแสดง | ไอคอนแถบบนข้างธงภาษา; บนโทรศัพท์ในเมนูมุมซ้ายบน |

## ตามงานวิเคราะห์และข้อค้นพบ (insight) ที่ระบบช่วยให้เห็น
| งาน | วิธีทำในระบบ | ตัวอย่างสิ่งที่เห็นได้ (จากข้อมูลจริง ไม่ใช่ข้อสรุปเชิงเหตุผล) |
|---|---|---|
| T1 ใครได้ที่นั่งมากที่สุด | การ์ดพรรค, แท่งสภา 500 ที่นั่ง, กราฟ A | ภูมิใจไทย 192 (เขต 173 + บัญชี 19); ประชาชนได้บัญชีรายชื่อมากที่สุด 32 ที่นั่ง |
| T2 แต่ละจังหวัดเลือกใคร | แผนที่โหมดพรรคชนะ + tooltip | กรุงเทพมหานคร 33 เขต ประชาชนชนะทั้ง 33 เขต; ขอนแก่น 11 เขต แบ่งให้ 4 พรรค |
| T3 ผลในจังหวัดหนึ่งครบทุกเขต | hover/คลิกจังหวัด หรือ bottom sheet บนมือถือ | ทุกจังหวัดแสดงผู้ชนะครบทุกเขต พร้อมคะแนนและส่วนต่าง |
| T4 เขตไหนสูสี | หน้าภาพรวม: KPI "เขตที่ชนะกันไม่ถึง 5%" + รายการ "เขตที่ชนะกันสูสีที่สุด" (ตามภูมิภาคที่กรอง) | 49 จาก 400 เขตชนะกันไม่ถึง 5%; สูสีที่สุดคือ นครราชสีมา เขต 3 (ห่าง 299 คะแนน, 0.32%) |
| T4b ใครคือคู่แข่งหลักของใคร | กราฟ B ใครชนะใคร (Sankey) + ตัวกรองภูมิภาค + คลิกพรรค | ภูมิใจไทยกับประชาชนชิงกัน 119 จาก 400 เขต (ภูมิใจไทยชนะ 83); ประชาชนได้อันดับสอง 140 เขต; อีสานเป็นภูมิใจไทย–เพื่อไทย 50 จาก 133 เขต |
| T5 ส.ส. ของแต่ละพรรคมาจากเขตหรือจากบัญชีรายชื่อ (แทนคำถาม "ใช้สิทธิสัมพันธ์กับความสูสีไหม" r ≈ −0.21 ซึ่งแทบไม่มีรูปแบบ) | กราฟ C (slope chart) + ตาราง | ภูมิใจไทย 173 เขต (43%) แต่บัญชีรายชื่อ 19 (19%); ประชาชนกลับกัน 88 เขต (22%) แต่บัญชีรายชื่อ 32 (32%) มากที่สุด; กล้าธรรม 56 → 2 |
| T5b ฐานเสียงของแต่ละพรรคกว้างแค่ไหน (ใหม่ 12 พ.ย. 2569) | กราฟ D อันดับของแต่ละพรรค (แท่งซ้อน) + ตัวกรองภูมิภาค + คลิกช่วงของแท่ง | ประชาชนติดสามอันดับแรก 363 จาก 399 เขตที่ส่ง (91%) แต่ชนะ 88; ภูมิใจไทยชนะ 173 จาก 394 เขต; กล้าธรรมชนะ 56 แต่อันดับ 4 ลงไป 199 เขต; ประชาธิปัตย์ส่ง 398 เขต ชนะ 10 |
| T6 รวมพรรคไหนถึงจะได้เสียงเกินครึ่งสภา และตอนนี้ใครเป็นรัฐบาล (แท็บของตัวเองตั้งแต่ 12 พ.ย. 2569) | แท็บ "รวมเสียงตั้งรัฐบาล" (บนโทรศัพท์แท็บ "สภา"): การ์ดฝ่ายรัฐบาล/ฝ่ายค้านใต้รูปสภา, คลิกพรรคในรายการหรือจุดในรูป, ปุ่มล้าง, ตาราง | ฝ่ายรัฐบาล 16 พรรค 293 เสียง เกินครึ่งสภา 42 เสียง ขาดภูมิใจไทยหรือเพื่อไทยไม่ได้; ฝ่ายค้าน 5 พรรค 149 เสียง; กล้าธรรม 58 เสียงไม่อยู่ทั้งสองฝ่าย (ณ 12 พ.ย. 2569); จากผลเลือกตั้งล้วน: ไม่มีพรรคใดถึง 251, ภูมิใจไทย + กล้าธรรม = 250 ขาดที่นั่งเดียว |
| T6b พรรคที่คนเลือกด้วยบัตรเลือกพรรคต่างจากพรรคที่ได้ที่นั่งไหม | สีแผนที่ "คะแนนเลือกพรรค" (ไม่ต้องเลือกพรรค) เทียบ "พรรคที่ชนะเขตมากที่สุด" | ประชาชนได้คะแนนเลือกพรรคมากที่สุดใน 40 จังหวัด; 43 จังหวัดสีต่างจากแผนที่ที่นั่ง; กรุงเทพฯ ทั้ง 33 เขตเหมือนกัน |

| T9 เทียบเขตที่สนใจ (ออกแบบใหม่ 12 พ.ย. 2569) | แท็บเปรียบเทียบ: ค้นหาด้วยชื่อพื้นที่หรือผู้สมัคร หรือเลือกจากจังหวัด / ปุ่มเพิ่มจากรายละเอียดเขต; ตารางเทียบข้างกัน 6 แถว | กรุงเทพฯ เขต 1 (ประชาชนชนะห่าง 25.1%) กับนครราชสีมา เขต 3 (ห่าง 0.32% "สูสีที่สุด") และบุรีรัมย์ เขต 3 (ภูมิใจไทยชนะห่าง 63.2%); ในกรุงเทพฯ เขต 1 พรรคที่นำบัตรเลือกพรรคตรงกับพรรคของผู้ชนะ |
