# ตารางการโต้ตอบ × งานวิเคราะห์ (Interaction–Task Matrix)

ประเภทการโต้ตอบตาม vis-10 p.5 (Select, Explore, Reconfigure, Encode, Abstract/Elaborate, Filter, Connect) ทุกแถวคือฟังก์ชันที่ทำงานจริงและมีการทดสอบใน `tests/two-page.e2e.cjs` เว้นแต่ระบุไว้

## ตามเทคนิค
| ประเภท | การโต้ตอบในระบบ | ตำแหน่ง |
|---|---|---|
| **Select** | คลิกการ์ดพรรค/แท่งพรรค/legend → ไฮไลต์พรรคทุกมุมมอง (การ์ดอื่นจาง แผนที่เปลี่ยนสีเป็นคลื่นจากฐานเสียงของพรรค กราฟละลายเข้าภาพใหม่); คลิกจังหวัด → ปักหมุดแผงจังหวัด; คลิกเขต/จุด/แถว → เลือกเขต (วงแหวน ตัวชี้ใต้ฮิสโทแกรม แถวสีฟ้า) เลือกจากค้นหาหรือรายการแล้วเขตบนแผนที่กระเพื่อม | ทั้งสองหน้า |
| **Explore** | แพน/ซูมแผนที่ (เมาส์ ล้อ ปุ่ม + − รีเซ็ต, สองนิ้วบนมือถือ); tooltip เปิดที่เมาส์และเลื่อนตาม เป็นบทสรุปสั้น คลิกเพื่อดูผลทุกเขต; ปุ่มลูกศรเลื่อนระหว่างจังหวัด | แผนที่ |
| **Abstract/Elaborate (ซูมเชิงความหมาย)** | คลิกจังหวัด → กล้องบินเข้าแล้วช่องหกเหลี่ยมบานเป็นขอบเขตเลือกตั้งจริงของจังหวัดนั้น (เลขเขตบนแผนที่ ชี้เพื่อดูชื่ออำเภอ/เขตในเขตนั้นและผล); รีเซ็ตหรือ "แผนที่ประเทศไทย" → เขตพับกลับ กล้องถอยออก จังหวัดอื่นกลับมาเป็นระลอก ทรานสิชันแสดงว่ามุมมองใหม่มาจากตรงไหน (ปิดเมื่อผู้ใช้ตั้งค่าลดการเคลื่อนไหว) | แผนที่ |
| **Reconfigure** | เรียงพรรค (รวม/เขต/บัญชี), แสดง 5/10/ทุกพรรค, เรียงเขตในดัมเบล (บัญชีสูงกว่า/ผู้สมัครสูงกว่า/ค่าสัมบูรณ์), เรียงแถวฮีตแมปตามพรรคที่เลือก | วิเคราะห์ |
| **Encode** | สีแผนที่ 4 แบบ (พรรคชนะ/ใช้สิทธิ/บัตรเสีย/สัดส่วนคะแนน + ชนิดบัตร), หน่วยส่วนต่าง %/คะแนน, ชั้นที่นั่ง เขต/บัญชีรายชื่อ/ทั้งสภา, มุมมองเมืองกับชนบท สรุปรายพรรค/รายจังหวัด, สเกลความหนาแน่น log/linear, ตัวชี้วัดฮีตแมป 4 แบบ, กราฟ ↔ ตาราง | ทั้งสองหน้า |
| **Abstract/Elaborate** | hover → tooltip จังหวัด → คลิกปักหมุด → คลิกเขต → ผู้สมัครทุกคน + คะแนนสองใบ; ดัมเบลรายพรรค → คลิกพรรค → รายเขต; ฮีตแมปภูมิภาค → รายจังหวัด | ทั้งสองหน้า |
| **Filter** | ตัวกรองภูมิภาค (ตัดเขตในทุกกราฟ ยกเว้นกราฟ A ที่ระบุว่าเป็นผลระดับประเทศ); ช่วงที่ลากในฮิสโทแกรมส่วนต่าง/beeswarm เสียงข้างมาก; ช่วงด่วนส่วนต่าง < 5%, 5–10%, 10–20% และคะแนนผู้ชนะ < 40%, 40–50%, ≥ 50% | ทั้งสองหน้า |
| **Connect** | ช่วงที่ลากเน้นจุดเดียวกันใน beeswarm เสียงข้างมาก ฮิสโทแกรม และจำกัดดัมเบลรายเขต; พรรคที่เลือกเปลี่ยนสีแผนที่ ฮิสโทแกรม beeswarm ฮีตแมป และไฮไลต์ในกราฟคะแนนกับที่นั่ง เมืองกับชนบท; ค้นหาผู้สมัครหรือชื่อพื้นที่ → เขต → จังหวัดบนแผนที่ | ทั้งสองหน้า |

## ความหมายของสถานะ (ไม่ให้กราฟเปลี่ยนแบบคาดไม่ถึง)
| สถานะ | ผล | แสดงที่ |
|---|---|---|
| ตัวกรองร่วม: ภูมิภาค | **ตัดข้อมูล** เขตนอกภูมิภาคไม่ถูกนับใน KPI/กราฟ B C D/ความหนาแน่น; แผนที่จาง | ชิป "ตัวกรอง" |
| ไฮไลต์: พรรค | **ไม่ตัดข้อมูล** เน้นเขต/จังหวัดที่พรรคชนะ; tooltip ยังแสดงผลครบทั้งจังหวัด และแสดง "0 เขต" ถ้าพรรคไม่ชนะในจังหวัดนั้น | ชิป "ไฮไลต์" |
| เลือก: จังหวัด/เขต | ปักหมุดรายละเอียด, วงแหวน/ตัวชี้ในกราฟ | ชิป "เลือก", breadcrumb |
| ช่วงที่ลาก (brush) | ชุดย่อยเขต ใช้กับกราฟในหน้าวิเคราะห์ ดูรายชื่อได้ | ชิป "ช่วงที่ลาก" |
| Hover | ชั่วคราว ไม่เปลี่ยนสถานะ | tooltip, วงแหวนฟ้า |
| ควบคุมเฉพาะกราฟ | เรียง/หน่วย/สเกล มีผลเฉพาะกราฟนั้น | แถวปุ่มในการ์ด |
| **Clear All** | ล้างทุกอย่างข้างบน + ซูมแผนที่ + รายการเปรียบเทียบ + แผงรายละเอียด กลับหน้าภาพรวม คงภาษา | แถบด้านข้าง |
| **อัปเดตข้อมูล** | อ่านไฟล์ข้อมูลใหม่ (ไม่ใช้แคช) วาดใหม่ในที่เดิมโดยคงทุกสถานะข้างบน ตัดเฉพาะสิ่งที่ไม่มีในข้อมูลใหม่แล้ว แจ้งจำนวนเขตที่เปลี่ยน แสดงเวลาที่โหลดล่าสุด ข้อมูลผิดไม่ถูกนำมาแสดง | ไอคอนแถบบนข้างธงภาษา |

## ตามงานวิเคราะห์และข้อค้นพบ (insight) ที่ระบบช่วยให้เห็น
| งาน | วิธีทำในระบบ | ตัวอย่างสิ่งที่เห็นได้ (จากข้อมูลจริง ไม่ใช่ข้อสรุปเชิงเหตุผล) |
|---|---|---|
| T1 ใครได้ที่นั่งมากที่สุด | การ์ดพรรค, แท่งสภา 500 ที่นั่ง, กราฟ A | ภูมิใจไทย 192 (เขต 173 + บัญชี 19); ประชาชนได้บัญชีรายชื่อมากที่สุด 32 ที่นั่ง |
| T2 แต่ละจังหวัดเลือกใคร | แผนที่โหมดพรรคชนะ + tooltip | กรุงเทพมหานคร 33 เขต ประชาชนชนะทั้ง 33 เขต; ขอนแก่น 11 เขต แบ่งให้ 4 พรรค |
| T3 ผลในจังหวัดหนึ่งครบทุกเขต | hover/คลิกจังหวัด หรือ bottom sheet บนมือถือ | ทุกจังหวัดแสดงผู้ชนะครบทุกเขต พร้อมคะแนนและส่วนต่าง |
| T4 เขตไหนสูสี | กราฟ B + ช่วงด่วน < 5% + รายชื่อ | 49 จาก 400 เขตชนะกันไม่ถึง 5%; สูสีที่สุดคือ นครราชสีมา เขต 3 (ห่าง 299 คะแนน, 0.32%) |
| T5 ใช้สิทธิสัมพันธ์กับความสูสีไหม | กราฟ C + r | r ≈ −0.21 (n = 400) ความสัมพันธ์อ่อน ไม่ใช่เหตุและผล |
| T6 คะแนนพรรค vs ผู้สมัคร | กราฟ D รายพรรค → รายเขต | ประชาชนมีสัดส่วนบัญชีรายชื่อสูงกว่าผู้สมัครราว +6 จุด; บางพรรค (เช่น ไทรวมพลัง) กลับกัน |
| T7 รูปแบบภูมิภาค | ฮีตแมป + รายจังหวัด | ประชาชนได้ 47.6% ของบัตรบัญชีรายชื่อในกรุงเทพฯ; ประชาธิปัตย์ 43.5% ในภาคใต้ |
| T8 บริบทประชากร | เมืองกับชนบท (สรุปรายพรรค + รายจังหวัด) | ประชาชนได้ 39.0% ในจังหวัดหนาแน่นเทียบ 30.2% ในจังหวัดเบาบาง (r = 0.45 บน log) เพื่อไทยกลับกัน 11.0% เทียบ 16.4% ภูมิใจไทยแทบเท่ากันทุกกลุ่ม (r ≈ 0.07) |
| T9 เทียบเขตที่สนใจ | แท็บเปรียบเทียบ / ปุ่มเพิ่มจากรายละเอียดเขต | เทียบใช้สิทธิ ส่วนต่าง บัตรเสีย และส่วนต่างสองบัตรบนสเกลเดียวกัน |
| T10 หาเขต/ผู้สมัคร | ค้นหาในแถบด้านข้าง (ชื่อจังหวัด, "เชียงใหม่ 3", ชื่อเขต/อำเภอ/ตำบลที่ระบุในเขต เช่น "บางรัก" หรือ "อำเภอโนนไทย", ชื่อผู้สมัคร, พรรค) | "บางรัก" → กรุงเทพฯ เขต 1; อำเภอโนนไทยอยู่ในนครราชสีมาเขต 3 และ 4 (แสดง "บางส่วน" ทั้งสองเขต); เลือกผู้สมัครแล้วเปิดผลเขตนั้นพร้อมไฮไลต์แถวผู้สมัคร |

ค่าตัวเลขในคอลัมน์สุดท้ายอ่านจากระบบที่รันกับชุดข้อมูล กกต. ณ 15 พ.ค. 2569 และตรวจซ้ำด้วยชุดทดสอบ
