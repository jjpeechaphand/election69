# แผนศึกษาการใช้งาน — รุ่นสองหน้า
รับสมัครประชาชนไทยประมาณ 5 คนที่มีประสบการณ์อ่านกราฟต่างกัน ขอความยินยอมก่อนจดบันทึก ใช้รหัส P01–P05 และไม่เก็บความเห็นทางการเมือง **ยังไม่มีผู้เข้าร่วมและไม่มีผลการทดสอบจริง**

1. (ภาพรวม) ระบุพรรคที่ได้ที่นั่งสูงสุด พร้อมแยกที่นั่ง สส.เขต กับบัญชีรายชื่อ — เฉลยจากตารางที่นั่ง กกต.
2. (แผนที่ + tooltip) ชี้กรุงเทพมหานคร แล้วบอกจำนวนเขต อัตราการใช้สิทธิ บัตรเสียแบบแบ่งเขต และผู้ชนะเขต 20 — เฉลยจาก data.json โดยผู้ประเมิน
3. (ปักหมุด) หาจังหวัดที่มีพรรคชนะเขตตั้งแต่ 4 พรรคขึ้นไป และเปิดดูผู้สมัครทุกคนในเขตหนึ่งของจังหวัดนั้น
4. (วิเคราะห์ B) เลือกช่วงส่วนต่างต่ำกว่า 5% บอกจำนวนเขต และเปิดรายชื่อเพื่อหาเขตที่สูสีที่สุด อธิบายตัวหารของส่วนต่างร้อยละ
5. (วิเคราะห์ C) อธิบายว่ากราฟอัตราใช้สิทธิกับส่วนต่างบอกอะไร และบอกอะไรไม่ได้ (ตรวจว่าผู้ใช้ไม่สรุปเหตุและผล)
6. (วิเคราะห์ D) เปรียบเทียบคะแนนผู้สมัครกับบัญชีรายชื่อของพรรคประชาชน ระดับพรรค แล้วเจาะดูรายเขต
7. ใช้ Clear All และสลับภาษา ตรวจว่ากลับถึงภาพรวมและหาข้อมูลเดิมได้ทั้งเดสก์ท็อปและมือถือ (bottom sheet)

ผู้ประเมินบันทึกรหัส ภารกิจ คำตอบจริง ถูก/ผิด ทำได้เอง/ขอความช่วยเหลือ เวลาตั้งแต่เริ่มจนตอบ จำนวนครั้งที่เลือกผิด คะแนนความง่าย 1–7 และคำอธิบายของผู้ใช้ ให้คำใบ้หลังบันทึกเวลาที่ต้องการความช่วยเหลือแล้ว วิเคราะห์เป็นจำนวนสำเร็จต่อจำนวนที่ทดลอง มัธยฐานเวลา และสาเหตุความสับสน แยกมือถือจากเดสก์ท็อป ไม่ใช้ผลจากกลุ่มเล็กประมาณผลของประชากร
