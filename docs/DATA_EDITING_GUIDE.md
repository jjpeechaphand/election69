# คู่มือแก้ไขและอัปเดตข้อมูลการเลือกตั้ง

ข้อมูลทุกอย่างที่หน้าเว็บแสดง (พรรค หัวหน้าพรรค แคนดิเดตนายกฯ ผู้สมัคร สส. คะแนน เขต จังหวัด จำนวนที่นั่ง วันเลือกตั้ง) อยู่ในไฟล์ตาราง CSV ที่เปิดแก้ด้วย Excel หรือ Google Sheets ได้ ไม่ต้องแก้โค้ด หน้าเว็บเหมือนเดิมทุกอย่าง และใช้ซ้ำกับการเลือกตั้งครั้งต่อไปได้โดยเพิ่มโฟลเดอร์ข้อมูลชุดใหม่

## 1. ข้อมูลอยู่ที่ไหน

```
dist/data/
  elections.csv            รายการการเลือกตั้งทั้งหมด และเลือกว่าจะแสดงครั้งไหน
  2569/                    ข้อมูลการเลือกตั้ง 8 ก.พ. 2569 (หนึ่งโฟลเดอร์ต่อการเลือกตั้งหนึ่งครั้ง)
    election.csv           ข้อมูลทั่วไป: วันเลือกตั้ง จำนวนที่นั่ง แหล่งข้อมูล เวลาอัปเดตของแหล่งข้อมูล
    parties.csv            พรรค สีพรรค หัวหน้าพรรค แคนดิเดตนายกฯ บุคคลและรูปบนการ์ด จำนวนที่นั่ง
    provinces.csv          จังหวัด ภาค จำนวนเขต ตำแหน่งบนแผนที่หกเหลี่ยม ความหนาแน่นประชากร
    constituencies.csv     เขตเลือกตั้ง พื้นที่ในเขต ผู้มีสิทธิ ผู้มาใช้สิทธิ บัตรดี บัตรเสีย (ทั้งสองบัตร)
    candidates.csv         ผู้สมัคร สส. แบ่งเขต: หมายเลข ชื่อ พรรค คะแนน
    party_list_votes.csv   คะแนนบัญชีรายชื่อรายเขต (หนึ่งแถวต่อเขต หนึ่งคอลัมน์ต่อพรรค)
    sources.csv            แหล่งข้อมูลที่แสดงในหน้าต่าง "ที่มาข้อมูลและวิธีอ่าน"
    export_manifest.json   ใช้ตรวจว่าการย้ายข้อมูลปี 2569 ถูกต้อง ไม่ต้องแก้
  bundle.js                สร้างอัตโนมัติจากไฟล์ CSV (สำหรับเปิดหน้าเว็บจากไฟล์ในเครื่อง) ห้ามแก้เอง
```

ผู้สมัครที่ได้คะแนนสูงสุดในแต่ละเขตคือ สส. เขตนั้น ระบบคำนวณผู้ชนะ ส่วนต่าง อัตราการใช้สิทธิ และสรุปทุกระดับจากตัวเลขในไฟล์เหล่านี้ให้เอง

## 2. เปิดและบันทึกไฟล์

- **Excel**: ดับเบิลคลิกเปิดได้เลย ภาษาไทยแสดงถูกต้อง เมื่อบันทึกให้เลือกชนิด **CSV UTF-8 (Comma delimited) (*.csv)** เท่านั้น (ถ้าบันทึกเป็น CSV ธรรมดา ภาษาไทยจะเสีย)
- **Google Sheets**: File → Import → Upload แล้วเมื่อแก้เสร็จ File → Download → Comma-separated values (.csv) แล้วตั้งชื่อไฟล์ให้ตรงเดิม
- **หัวคอลัมน์**: ชื่อภาษาอังกฤษในวงเล็บท้ายหัวคอลัมน์ เช่น `คะแนน (votes)` คือชื่อที่ระบบใช้ ห้ามแก้ ส่วนคำภาษาไทยหน้าวงเล็บแก้ได้ สลับลำดับคอลัมน์ได้ คอลัมน์ที่ระบบไม่รู้จักจะถูกข้าม (ยกเว้น party_list_votes.csv ที่ทุกคอลัมน์หลังรหัสเขตต้องเป็นชื่อพรรค) แถวว่างจะถูกข้าม
- **ตัวเลข**: ใส่ `1234` หรือ `1,234` ก็ได้ เป็นจำนวนเต็มไม่ติดลบ **ช่องว่าง = ยังไม่มีข้อมูล** (ระบบแสดง "ข้อมูลไม่ครบ" ไม่นับเป็น 0) ยกเว้นคะแนนผู้สมัครที่ต้องใส่ทุกคน ถ้ายังไม่มีให้ใส่ 0
- **หลายค่าในช่องเดียว** (พื้นที่ในเขต, รายชื่อแคนดิเดตนายกฯ) ให้คั่นด้วย ` | `
- **ใช่/ไม่ใช่**: ใส่ `ใช่` (หรือ yes, 1, x) และ `ไม่ใช่` หรือเว้นว่าง
- **ชื่อพรรคต้องตรงกันทุกตัวอักษร** ใน parties.csv, candidates.csv และหัวคอลัมน์ party_list_votes.csv

## 3. งานที่ทำบ่อย

### 3.1 อัปเดตผลระหว่างนับคะแนน
1. แก้คะแนนใน `candidates.csv` (คอลัมน์ votes) และตัวเลขบัตรใน `constituencies.csv` ตามที่ได้รับรายงาน
2. ถ้ามีคะแนนบัญชีรายชื่อ แก้ `party_list_votes.csv`
3. ใน `election.csv` แก้ `source_updated_at` เป็นเวลาที่แหล่งข้อมูลประกาศ (หัวเว็บจะแสดง "ข้อมูลจาก กกต. ณ ...") และ `counted_percent` ถ้ามี
4. ที่นั่ง สส. เขต ใน `parties.csv` ปล่อยว่างได้ ระบบนับจากผู้ชนะแต่ละเขตให้เอง ส่วนที่นั่งบัญชีรายชื่อใส่เมื่อ กกต. ประกาศ
5. บันทึกไฟล์ แล้วอัปโหลดขึ้นเซิร์ฟเวอร์ที่ใช้เผยแพร่เว็บ
6. ผู้ใช้กดปุ่มอัปเดต (ไอคอนลูกศรวนที่มุมขวาบน) หรือเปิดหน้าใหม่ ก็เห็นตัวเลขใหม่ทันที ระบบบอกว่ามีกี่เขตที่ข้อมูลเปลี่ยน

### 3.2 แก้ชื่อหรือรายละเอียด
| ต้องการแก้ | ไฟล์ / คอลัมน์ |
|---|---|
| ชื่อผู้สมัคร สส. หรือพรรคของผู้สมัคร | `candidates.csv` name, party |
| หัวหน้าพรรค | `parties.csv` party_leader |
| แคนดิเดตนายกรัฐมนตรี | `parties.csv` pm_candidates (คั่นหลายคนด้วย ` \| `) |
| บุคคลและรูปบนการ์ดพรรค | `parties.csv` card_person, card_is_pm_candidate, photo, photo_fallback |
| พรรคที่แสดงเป็นการ์ด | `parties.csv` show_card (ออกแบบไว้ 10 ใบ ห้าคอลัมน์สองแถว) |
| สีพรรค | `parties.csv` color แบบ #RRGGBB |
| พื้นที่ในเขต (อำเภอ/เขต/ตำบล) | `constituencies.csv` areas |
| ชื่อจังหวัด ภาค จำนวนเขต | `provinces.csv` |

รูปบุคคลให้วางไฟล์ไว้ใน `dist/assets/candidates/` แล้วใส่เส้นทาง เช่น `assets/candidates/anutin.png` (PNG พื้นหลังโปร่งใส ภาพจัตุรัส ศีรษะอยู่ช่วงบน)

รูปผู้สมัครแบบแบ่งเขตไม่ต้องใส่ทีละแถว: ตั้ง `candidate_photos` ใน election.csv ครั้งเดียว แล้ววางไฟล์ชื่อตามรหัสผู้สมัครของ กกต. ไว้ในโฟลเดอร์นั้น (ชุด 2569 อยู่ที่ `dist/assets/candidates/2569/` สร้างด้วย `scripts/fetch_mp_portraits.py` แล้ว `scripts/prepare_mp_portraits.py` ซึ่งตัดพื้นหลังและจัดกรอบเหมือนรูปหัวหน้าพรรค ดู DATA_PIPELINE.md) ถ้าผู้สมัครคนใดไม่มีรูป ให้ใส่รหัสใน `candidate_photos_missing` สคริปต์ตรวจข้อมูลจะเตือนเมื่อพบผู้สมัครที่ไม่มีไฟล์รูปและไม่อยู่ในรายการนี้

### 3.3 เพิ่มการเลือกตั้งครั้งใหม่ (เช่น ปี 2573)
1. คัดลอกโฟลเดอร์ `dist/data/2569` เป็น `dist/data/2573` (ไม่ต้องคัดลอก export_manifest.json)
2. แก้ `election.csv`: election_id = 2573, election_date, จำนวนที่นั่ง, source_updated_at และล้างค่า official_* กับ check_* ที่เป็นของปีเก่า
3. แก้ `parties.csv` เป็นพรรคที่ลงสมัครครั้งนั้น `provinces.csv` ถ้าจำนวนเขตต่อจังหวัดเปลี่ยน `constituencies.csv` และ `candidates.csv` เป็นเขตและผู้สมัครใหม่ ช่วงก่อนนับคะแนนใส่คะแนน 0
4. แก้หัวคอลัมน์ `party_list_votes.csv` ให้เป็นชื่อพรรคชุดใหม่
5. ถ้ามีการแบ่งเขตใหม่ ต้องมีไฟล์ขอบเขตเขตเลือกตั้งชุดใหม่สำหรับแผนที่รายเขต แล้วใส่ชื่อไฟล์ใน `district_shapes` (ดูข้อ 6)
6. เพิ่มแถวใน `dist/data/elections.csv` แล้วตั้ง "แสดงบนเว็บ" = ใช่ ให้ครั้งใหม่ และ ไม่ใช่ ให้ครั้งเก่า
7. ดูตัวอย่างก่อนเปิดจริงได้ด้วยการเติม `?election=2573` ท้ายที่อยู่เว็บ (ไม่ต้องเปลี่ยน active)

หน้าเว็บจะเปลี่ยนตามเองทั้งหมด เช่น โลโก้ ELECTION73 หัวข้อวันเลือกตั้ง จำนวนที่นั่ง เส้นเสียงข้างมาก และจำนวนเขต

### 3.4 เปิดหน้าเว็บจากไฟล์ในเครื่อง (ออฟไลน์)
เบราว์เซอร์ไม่อนุญาตให้หน้าที่เปิดจากไฟล์ (file://) อ่านไฟล์ CSV โดยตรง จึงใช้ `dist/data/bundle.js` ซึ่งรวมไฟล์ CSV ทั้งหมดไว้ หลังแก้ CSV ทุกครั้งให้สร้างใหม่ด้วยการดับเบิลคลิก `build-data.bat` (ในโฟลเดอร์ output/election69) หรือสั่ง

```
python -I -X utf8 scripts/build_data_bundle.py
```

ถ้าเผยแพร่บนเว็บเซิร์ฟเวอร์ หน้าเว็บอ่าน CSV โดยตรง bundle.js ใช้เฉพาะเมื่ออ่าน CSV ไม่ได้

## 4. ตรวจข้อมูลก่อนเผยแพร่
- `python -I -X utf8 scripts/build_data_bundle.py --check` ตรวจทุกไฟล์โดยไม่สร้าง bundle แจ้ง **ข้อผิดพลาด** (ต้องแก้ก่อน) และ **คำเตือน** (เช่น คะแนนผู้สมัครรวมไม่เท่าบัตรดี จำนวนเขตไม่ตรงกับ provinces.csv ไม่พบไฟล์รูป) พร้อมบอกไฟล์ แถว และคอลัมน์
- ถ้ามีข้อมูลผิดขึ้นเว็บ ปุ่มอัปเดตจะไม่นำข้อมูลนั้นมาแสดง แต่คงข้อมูลเดิมไว้และขึ้นข้อความ "อัปเดตไม่สำเร็จ ยังแสดงข้อมูลเดิม" พร้อมตำแหน่งที่ผิด เช่น `2569/candidates.csv แถว 12 คอลัมน์ votes: ต้องเป็นจำนวนเต็มไม่ติดลบ`
- หน้าต่าง "ที่มาข้อมูลและวิธีอ่าน" แสดงผลตรวจภายใน เช่น ที่นั่งรวมเท่ากับจำนวนที่นั่งทั้งหมด ผลรวมรายเขตเท่ากับยอดที่ประกาศ (official_* ใน election.csv)

## 5. ปุ่มอัปเดตข้อมูลบนหน้าเว็บ
- อยู่มุมขวาบนข้างธงภาษา ข้างปุ่มแสดง "อัปเดตล่าสุด" พร้อมเวลาที่ผู้ใช้เปิดหน้าเว็บหรือกดปุ่มครั้งล่าสุด (บนมือถืออยู่ใต้ธงภาษา)
- กดแล้วระบบอ่านไฟล์ข้อมูลใหม่จากเซิร์ฟเวอร์โดยไม่ใช้แคช วาดหน้าใหม่ในที่เดิม จังหวัด เขต พรรค และตัวกรองที่เลือกไว้ยังอยู่ แล้วแจ้งว่ามีกี่เขตที่ข้อมูลเปลี่ยน
- ถ้าเปลี่ยนการเลือกตั้งที่แสดง (active) ระหว่างนั้น หน้าเว็บจะโหลดใหม่ทั้งหน้า

### election.csv (หนึ่งแถวต่อหนึ่งค่า: key, value, note)

| check_* | ผลตรวจเทียบกับเว็บไซต์ กกต. (ไม่บังคับ) แสดงในหน้าต่างที่มาข้อมูล |

## 7. ข้อจำกัดที่ควรรู้
- แผนที่รายเขตต้องมีไฟล์ขอบเขต (`district-shapes.js` สร้างโดย `scripts/prepare_two_page.py` จาก geography.json) ถ้ามีการแบ่งเขตใหม่ต้องเตรียมไฟล์ขอบเขตชุดใหม่ที่ใช้รหัสเขตแบบเดียวกัน
- ถ้ามีจังหวัดใหม่ ต้องกำหนดตำแหน่งหกเหลี่ยมที่ว่างให้จังหวัดนั้นใน provinces.csv
- การ์ดพรรคออกแบบไว้ 10 ใบ ถ้าตั้ง show_card มากกว่า 10 พรรค การ์ดจะเพิ่มแถว
- ข้อความอธิบายบางส่วนอ้างถึง กกต. และระบบเลือกตั้งแบบสองบัตร (แบ่งเขต + บัญชีรายชื่อ) ตามระบบปัจจุบัน
