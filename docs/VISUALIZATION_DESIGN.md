# การออกแบบภาพข้อมูล (Visualization Design)

ผู้ใช้หลัก: ประชาชนทั่วไปที่อยากเข้าใจผลเลือกตั้ง สส. 8 ก.พ. 2569 · ผู้ใช้รอง: สื่อมวลชน นักศึกษา นักวิจัย
ระบบมีสองหน้าที่เสริมกัน: **ภาพรวม** ตอบ "เกิดอะไรขึ้น" อย่างรวดเร็ว และ **วิเคราะห์ข้อมูล** ตอบ "เพราะอะไร/มีรูปแบบอะไร" ด้วยกราฟเชิงปริมาณ

## หน้า 1 — ภาพรวม
| องค์ประกอบ | Mark / Channel | เหตุผล |
|---|---|---|
| KPI 4 ค่า | ตัวเลขขนาดใหญ่ + คำอธิบายตัวหาร | ค่าเดี่ยวไม่จำเป็นต้องเป็นกราฟ (stat tile) ทุกค่ามีนิยาม |
| การ์ดพรรค 10 ใบ (คืนจากฉบับเดิม) | สีขอบบน = สีพรรค, ตัวเลขใหญ่ = ที่นั่งรวม, แถบเล็ก = สัดส่วน สส.เขต ต่อที่นั่งรวม, ภาพแคนดิเดตนายกฯ | ให้ผู้ใช้ทั่วไปจำพรรคได้ทันทีจากบุคคลและสี ภาพเต็มครึ่งขวาของการ์ดใต้ชื่อพรรคและตัดที่ว่างเหนือศีรษะออก ใบหน้าจึงใหญ่พอจำได้จากระยะไกล โดยไม่ทับตัวเลข พรรคอื่น 12 พรรคสรุปเป็นแถวเดียวพร้อมลิงก์ไปกราฟ A |
| แผนที่หกเหลี่ยม 77 จังหวัด | Mark = หกเหลี่ยมขนาดเท่ากัน 1 ช่อง/จังหวัด, Channel = สี (พรรคที่ชนะเขตมากที่สุด / ความเข้มของพรรคที่เลือก / อัตราใช้สิทธิ / บัตรเสีย / สัดส่วนคะแนน), ลายแถบ = เสมอกัน | tile grid ทำให้จังหวัดเล็กอย่างสมุทรสงครามมองเห็นเท่ากรุงเทพฯ แผนที่ไม่ได้แทนเขตเลือกตั้งและไม่ใช่ขอบเขตจริง |
| ป้ายชื่อในช่อง | ชื่อจังหวัดเต็มทุกช่องตลอดเวลา 1–3 บรรทัด ตัดตามขอบคำ (อังกฤษตัดตามพยางค์พร้อมยัติภังค์) ขนาดปรับตามช่องตั้งแต่ 8.5px สีตัวอักษรเลือกตามความสว่างพื้น | ห้ามใช้อักษรย่อ legend วางในพื้นที่อ่าวไทยว่างโดยคำนวณจากตำแหน่งช่องจริงเพื่อไม่บังจังหวัดใด เมื่อพื้นที่ว่างไม่พอ (เช่น 1024–1440px) legend พับเป็นปุ่ม "คำอธิบายสี" กดเพื่อเปิด |
| Tooltip จังหวัด | ส่วนหัว (ชื่อเต็ม + จำนวนเขต) → สถิติ 6 ช่อง → แถบที่นั่งรายพรรค → "คลิกเพื่อดูผลทั้ง N เขตและแผนที่รายเขต" → นิยาม เปิดห่างจากเมาส์ 18px และเลื่อนตามเมาส์ | เป็นบทสรุปสั้น (ตั้งแต่ 6 พ.ย. 2569 ไม่มีรายชื่อผู้ชนะทุกเขตแล้ว เพราะยาวเกินไปสำหรับการชี้ผ่าน) ผลรายเขตครบทุกเขตอยู่ในแผงที่เปิดเมื่อคลิก และใน bottom sheet บนมือถือ; สีพรรคเป็นจุดเล็กเท่านั้น ตัวเลขชิดขวาแบบ tabular; ระหว่างตามเมาส์ tooltip ไม่รับเมาส์ จึงไม่บังช่องที่กำลังชี้ |
| แผนที่รายเขต (คลิกจังหวัด) | Mark = ขอบเขตเลือกตั้งจริง (polygon), สี = พรรคผู้ชนะ, ป้าย = เลขเขต, tooltip = ชื่ออำเภอ/เขตในเขตนั้น (ตัวหนา) + ตำบลที่ระบุ (ตัวเล็ก) + ผู้ชนะ พรรค คะแนน ส่วนต่าง ใช้สิทธิ | เป็นการซูมเชิงความหมาย (semantic zoom): ระดับประเทศใช้ tile เท่ากันเพื่อเทียบจังหวัด ระดับจังหวัดใช้รูปร่างจริงเพราะผู้ใช้ต้องการรู้ว่า "เขตไหนคือแถวไหน" ขอบเขตเป็นค่าประมาณจากชุมชน ระบุที่มาในคำอธิบาย |
| เครดิตแผนที่ | บรรทัดเล็กใต้แผนที่ นอกกรอบ: "แผนที่ประเทศไทยแบบหกเหลี่ยม: อ้างอิงรูปแบบจาก Hex Map of Thailand (ลิงก์) ผลงานของ ผศ. ดร. ภูริพันธุ์ รุจิขจร อาจารย์ประจำภาควิชาสถิติ จุฬาลงกรณ์มหาวิทยาลัย และผู้ร่วมก่อตั้ง Boonmee Lab" หรือ ขอบเขต Thai-ECT-election-map โดย Kittapat Ratanaphupha ตามแผนที่ที่แสดงอยู่ | ให้เครดิตผู้จัดทำโดยไม่แย่งพื้นที่และไม่ซ่อนในคำอธิบายสีที่อาจถูกพับ |
| การเคลื่อนไหวเมื่อเลือก | พรรค: การ์ดอื่นจางและลดสี การ์ดที่เลือกขยายขึ้น 5% แบบเด้งเล็กน้อยและมีวง แผนที่เปลี่ยนสีเป็นคลื่นจากจังหวัดที่พรรคชนะมากที่สุด (≈0.75 วินาที) แถวและแท่งในแผงค่อย ๆ เปลี่ยน; ค้นหา/เลือกจากรายการ: บินเข้าจังหวัดแล้วเขตที่เลือกกระเพื่อม ผู้สมัครเลื่อนมากลางแผงและกะพริบ; แผงขวาเลื่อนตามทิศของลำดับชั้น; หน้าวิเคราะห์ละลายภาพเก่าเข้าภาพใหม่ | การเคลื่อนไหวตอบการกระทำของผู้ใช้และบอกว่าอะไรเปลี่ยน ที่ไหน: คลื่นสีชี้ฐานเสียงของพรรค วงกระเพื่อมช่วยหาเขตที่เลือก ทิศการเลื่อนบอกว่าลงลึกหรือย้อนกลับ ไม่มีการเคลื่อนไหวที่ไม่ได้เกิดจากผู้ใช้ และปิดทั้งหมดเมื่อผู้ใช้ตั้งค่าลดการเคลื่อนไหว |
| ทรานสิชันแผนที่ | เข้า: จังหวัดอื่นจางเหลือ 7% กล้องบิน 760 ms (easeCubicInOut) เข้าหาช่องที่คลิก แล้วช่องจางออกขณะเขต "บาน" จากเขตใกล้กลางออกไป (ขยาย 0.8→1 แบบเด้งเล็กน้อย) ออก: เขตพับกลับ 280 ms กล้องถอย 900 ms จังหวัดอื่นกลับมาเป็นระลอกตามระยะห่างจากจังหวัดเดิม | ทรานสิชันรักษาความต่อเนื่องของวัตถุ (object constancy) ผู้ใช้เห็นว่าแผนที่รายเขตคือ "ข้างใน" ช่องที่คลิก และกลับมาที่เดิม ระยะเวลา < 1 วินาทีต่อทาง; ผู้ใช้ที่ตั้งค่าลดการเคลื่อนไหวและ Clear All สลับทันที |
| แผงบริบท (ขวา) | องค์ประกอบสภา 500 ที่นั่ง (แท่งซ้อน + เส้นเสียงข้างมาก 251), เขตสูสีที่สุด 6 เขต | เป็นบทสรุปที่แผนที่ไม่บอก เมื่อเลือกจังหวัด/เขตจะแทนที่ด้วยรายละเอียดเดียวกับ tooltip; รายชื่อจังหวัดเต็ม 77 จังหวัดตามภูมิภาค (สีพรรคที่นำ + จำนวนเขต) ถูกนำออกเมื่อ 7 พ.ย. 2569 ตามผู้ใช้ เพราะซ้ำกับแผนที่ ทุกจังหวัดยังเข้าถึงได้ด้วยคีย์บอร์ดบนแผนที่ (ลูกศร + Enter) การค้นหา และตัวกรองจังหวัด |
| สีแผนที่ (7 พ.ย. 2569) | ตัวเลือกจัดกลุ่ม: **ที่นั่ง** — พรรคที่ชนะเขตมากที่สุด; **คะแนนเสียง** — คะแนนเลือกพรรค (บัญชีรายชื่อ), คะแนนเลือกผู้สมัคร (แบ่งเขต); **การใช้สิทธิ** — อัตราการใช้สิทธิ, สัดส่วนบัตรเสีย; ไม่เลือกพรรค: สีคือพรรคที่ได้คะแนนบัตรนั้นมากที่สุดในจังหวัด/เขต พร้อมบอกว่ากี่จังหวัดสีต่างจากแผนที่ที่นั่ง; เลือกพรรค: ความเข้มสี = สัดส่วนคะแนนบัตรนั้นของพรรค | เดิมสองบัตรเป็นตัวเลือกย่อยใต้ "สัดส่วนคะแนนของพรรคที่เลือก" และต้องเลือกพรรคก่อน ผู้ใช้เห็นว่าสำคัญกว่านั้น ข้อมูลยืนยัน: บนบัตรเลือกพรรค ประชาชนนำ 40 จังหวัด ขณะที่ภูมิใจไทยนำที่นั่ง 43 จังหวัดสีต่างจากแผนที่ที่นั่ง (ระดับเขต 209 จาก 400 เขตพรรคที่ได้คะแนนเลือกพรรคมากสุดไม่ใช่พรรคของผู้ชนะ); ชื่อใช้คำเดียวกับแผงเขต (บัตรเลือกพรรค/บัตรเลือกผู้สมัคร) ซึ่งคนทั่วไปเข้าใจ ส่วนชื่อทางการอยู่ในคำอธิบายสีและ tooltip ของตัวเลือก เพื่อให้เมนูสั้นพอที่จอ 1024 px |
| เลขเขตบนแผนที่รายเขต (7 พ.ย. 2569) | เลขอยู่ชั้นบนสุดแยกจากรูปเขต วางที่ "จุดกลางสายตา" ของแต่ละเขต (จุดในรูปที่ไกลจากขอบที่สุด — pole of inaccessibility) ขนาดเดียวกันทุกเขตที่มีที่พอ เขตแคบลดขนาดให้อยู่ในรูป (ต่ำสุด 10px) มีขอบตัวอักษรสีตรงข้ามจาง ๆ ซูมแล้วเลขขยายตามพื้นที่ที่มี | เดิมใช้จุด centroid ซึ่งอยู่นอกรูปหรือชิดขอบสำหรับเขตที่โค้งหรือยาว และวาดเลขในกลุ่มเดียวกับรูป เขตที่วาดทีหลังจึงบังเลขของเขตก่อนหน้า; ตรวจแล้วเลขทุกตัวอยู่ในเขตของตน |
| จังหวัดที่ชี้ยกตัวขึ้น (7 พ.ย. 2569) | ช่องที่ชี้ (หรือโฟกัสด้วยคีย์บอร์ด) ขยาย 1.14 เท่าแบบเด้งเล็กน้อย 0.24 วินาที ลอยเหนือช่องข้างเคียงพร้อมเงาและขอบเรืองแสง สีข้อมูลเดิม | บอกตำแหน่งที่ชี้ชัดขึ้นโดยไม่เปลี่ยนสีข้อมูล ทำเป็นสำเนาที่ไม่รับเมาส์วาดทับ ช่องจริงไม่ถูกย้ายใน DOM (การย้ายจะทำให้คีย์บอร์ดหลุดโฟกัส); ปิดการเคลื่อนไหวเมื่อผู้ใช้ตั้งค่าลดการเคลื่อนไหว |
| ภาพผู้สมัคร (7 พ.ย. 2569: แผงเขต แผงจังหวัด ผลค้นหา) | ภาพทางการของ กกต. ทุกคน ไดคัตในกรอบเดียวกับภาพหัวหน้าพรรค (ใบหน้าขนาดและตำแหน่งเดียวกัน); **ขนาดตามอันดับ**: ผู้ชนะ 150 px ในการ์ดผู้ชนะ ยืนชิดขอบล่างแบบภาพบนการ์ดพรรค มีแสงสีพรรคหลังศีรษะ > อันดับสอง 48 px ในแถว "อันดับสอง" ใต้การ์ดผู้ชนะพร้อมส่วนต่างคะแนน > ทุกคนในรายการคะแนน 34 px; ผู้ชนะทุกเขตในแผงจังหวัด 34 px; ผลค้นหาผู้สมัคร 30 px; วงพื้นหลังเป็นสีพรรคอ่อน; ไม่มีภาพ (ผู้ถูกถอนชื่อ เขตที่ยังไม่มีผู้ชนะ) = รูปสัญลักษณ์เรียบ ๆ ที่ไม่ใช่ภาพบุคคล | ให้ผู้ใช้ทั่วไปเห็นว่า สส. ที่ได้รับเลือกคือใคร ขนาดภาพบอกลำดับผลได้ทันทีโดยไม่ต้องอ่านตัวเลข จึงมีภาพใหญ่เฉพาะผู้ชนะ; จัดใบหน้าให้เท่ากันเพื่อไม่ให้ภาพต้นฉบับที่ถ่ายใกล้/ไกลต่างกันถูกอ่านเป็นความสำคัญต่างกัน; อันดับสองย้ายออกจากช่องสถิติมาอยู่ใต้ผู้ชนะ เพราะส่วนต่างคือระยะห่างระหว่างสองคนนี้ ช่องสถิติเหลือ 4 ค่าเรียงแถวเดียว (แคบลงเป็น 2×2 ตามความกว้างแผง); ภาพเป็นส่วนเสริม (alt ว่าง) เพราะชื่ออยู่ข้างภาพเสมอ และชื่อตัดบรรทัดระหว่างคำ ไม่ตัดกลางนามสกุล |

## หน้า 2 — วิเคราะห์ข้อมูล
ทบทวนใหม่ 6 พ.ย. 2569: แต่ละกราฟต้องมีข้อค้นพบที่ใช้ได้จริง กราฟที่ข้อมูลไม่มีรูปแบบให้เห็นถูกแทนด้วยหัวข้อที่ข้อมูลบอกอะไรชัดเจน (ตัวเลขจากการสำรวจข้อมูลชุด 2569 ทั้ง 400 เขต)

ทบทวนรอบ 7 พ.ย. 2569 (ตามผู้ใช้): A และ D เคยเป็นดัมเบลเหมือนกัน จึงเลือกประเภทกราฟใหม่ตามชนิดข้อมูลของแต่ละคำถาม ให้ 4 กราฟหลักเป็น 4 ประเภทที่ต่างกัน — สองค่าหน่วยเดียวกันต่อพรรค → กราฟกระจายเทียบเส้น "ที่นั่ง = คะแนน" (A); ความสัมพันธ์ระหว่างสองหมวด (พรรคผู้ชนะ → พรรคอันดับสอง) ที่มีจำนวนเป็นค่า → แผนภาพการไหล Sankey (B, แทนฮิสโทแกรมส่วนต่างตามผู้ใช้); ค่าเดียวกันในสองประเภทที่นั่ง ที่อันดับสลับกัน → slope chart (C); ผลต่างที่มีทิศทางต่อพรรค/เขต → แท่งเบี่ยงออกจากศูนย์ (D) และแทนกราฟ "ได้เสียงข้างมากไหม" ด้วย ส.ส.เขตกับบัญชีรายชื่อ

ทบทวนรอบ 11 พ.ย. 2569 (ตามผู้ใช้): "คะแนนคนกับคะแนนพรรค" (D เดิม) เล่าเรื่องเดียวกับ A และ C เป็นครั้งที่สาม และ "เมืองกับชนบท" ไม่ให้ประโยชน์กับผู้ใช้ ทั้งสองกราฟถูกนำออก แทนด้วยสองหัวข้อที่กราฟอื่นไม่ตอบ: **รวมเสียงตั้งรัฐบาล** (D ใหม่ — ส่วนของทั้งหมดเทียบกับเกณฑ์ ที่ต่างกันแค่ที่นั่งเดียวก็มีความหมาย → รูปสภาแบบหนึ่งจุดต่อหนึ่งที่นั่ง) และ **ที่สุดของผู้สมัคร** (ค่าเดียวต่อผู้สมัคร เรียงอันดับ → แท่งเรียงอันดับพร้อมภาพ) หัวข้อที่พิจารณาแล้วไม่เลือก: อัตราการใช้สิทธิและบัตรเสีย (มีใน KPI และสีแผนที่ของหน้าภาพรวมแล้ว), คะแนนที่ไม่ได้ที่นั่ง (ซ้ำ A), อันดับของผู้สมัครแต่ละพรรค (ซ้ำ B), เพศของผู้สมัคร (ต้องอนุมานจากคำนำหน้าชื่อ และไม่มีรายชื่อ ส.ส.บัญชีรายชื่อ)

ทบทวนรอบ 12–13 พ.ย. 2569 (ตามผู้ใช้ "ต้องการให้ทุกจอที่เปิดบน Desktop เป็นแบบโชว์ 4 กราฟ ... ถ้าต้องการดูรายละเอียดเพิ่มเติมให้กดเข้าไปในกราฟ"): บนเดสก์ท็อปแท็บแรกแสดง 4 กราฟพร้อมกันทุกขนาดจอ (เดิมจอเตี้ยกว่า 860 px หรือแคบกว่า 1280 px เหลือทีละกราฟ) แต่ละกราฟเป็น **ภาพย่อ** ที่มีชื่อสั้น ข้อค้นพบแบบสั้นหนึ่งบรรทัด และตัวกราฟ ไม่มีตัวเลือก คำอธิบาย หรือปุ่มตารางให้รก ภาพย่อลดรายละเอียดเอง (ป้ายที่วางไม่ลงถูกละ พรรคเล็กไม่แสดง) จุดในภาพย่อยังมี tooltip ที่บอกว่า "คลิกเพื่อขยายกราฟนี้" และไม่รับคลิกของตัวเอง; คลิกที่ใดก็ได้บนภาพย่อ (หรือปุ่ม "ขยาย") เปิดกราฟนั้นใหญ่ โดยการ์ดขยายออกจากตำแหน่งเดิม (0.32 วินาที) พร้อมคำถาม ข้อค้นพบเต็ม ตัวเลือก คำอธิบายท้ายการ์ด และมุมมองตาราง; แถบเหนือกราฟมี "กลับไปภาพรวม 4 กราฟ" (กราฟหดกลับเข้าที่) และปุ่มไปอีกสามกราฟ ปุ่ม Esc ก็กลับได้ และคีย์บอร์ดย้ายไปที่ปุ่มกลับ/ภาพย่อเดิมให้ — เป็นแบบภาพรวมก่อน แล้วขยาย แล้วดูรายละเอียดเมื่อต้องการ (Shneiderman, 1996); **รวมเสียงตั้งรัฐบาล** ย้ายเป็นแท็บของตัวเองระหว่าง "ที่สุดของผู้สมัคร" กับ "เปรียบเทียบเขตที่สนใจ" เพราะเป็นคนละคำถามกับสามกราฟ (สามกราฟถามว่าแต่ละพรรคได้ผลอย่างไร กราฟนี้ถามว่าใครตั้งรัฐบาลได้) และใต้รูปสภาเพิ่มข้อมูลปัจจุบันว่าใครเป็นรัฐบาลและฝ่ายค้าน; กราฟที่สี่ของภาพรวมเป็นกราฟใหม่ **อันดับของแต่ละพรรค** (D, แท่งซ้อน) ซึ่งเป็นประเภทที่ต่างจากสามกราฟและผูกสามกราฟเข้าด้วยกัน; **เปรียบเทียบเขตที่สนใจ** ออกแบบใหม่เป็นตารางเทียบข้างกันพร้อมช่องค้นหา

|---|---|---|---|
| A คะแนนกับที่นั่ง (ใหม่ แทน "ที่นั่งในสภา"; เป็นกราฟกระจายตั้งแต่ 7 พ.ย.) | แต่ละพรรคได้ที่นั่งเกินหรือขาดจากคะแนนเสียงแค่ไหน | กราฟกระจาย x = สัดส่วนคะแนน, y = สัดส่วนที่นั่ง สเกลเดียวกันทั้งสองแกน 1 จุด = 1 พรรค; เส้นประ "ที่นั่ง = คะแนน" พื้นเหนือเส้นแรเงา "ได้ที่นั่งเกินคะแนน"; ก้านสีพรรคจากจุดถึงเส้นคือส่วนต่าง; ป้าย "ภูมิใจไทย +12.3" เฉพาะพรรคที่ได้ ≥ 10 ที่นั่งหรือ ≥ 3% วางป้ายไม่ให้ทับกัน; เลือกชั้นที่นั่ง ส.ส.เขต (400) / บัญชีรายชื่อ (100) / ทั้งสภา (500) | สองค่าเชิงปริมาณหน่วยเดียวกันต่อหนึ่งหน่วย (Q×Q) ใช้กราฟกระจาย และความสัมพันธ์ที่ถามคือความได้สัดส่วน ซึ่งเส้น y = x แสดงตรง ๆ (แบบกราฟที่นั่ง–คะแนนในงานรัฐศาสตร์); กราฟที่นั่งเดิมซ้ำกับการ์ดพรรคและแถบสภาในหน้าภาพรวม หัวข้อใหม่ตอบเรื่องที่หน้าแรกไม่บอก: ภูมิใจไทยได้ 43.3% ของที่นั่งเขตจากคะแนน 30.9% ขณะที่ประชาชนได้คะแนนบัญชีรายชื่อมากที่สุด 31.5% แต่ได้ที่นั่งทั้งสภา 24% (ระบบแบ่งเขตให้ที่นั่งเกินกับพรรคที่นำ บัญชีรายชื่อแบ่งตามคะแนน); เขต: คะแนนผู้สมัคร ÷ บัตรดีแบบแบ่งเขต, บัญชี: คะแนนพรรค ÷ บัตรดีบัญชีรายชื่อ, ทั้งสภา: เทียบกับคะแนนบัญชีรายชื่อ |
| B ใครชนะใคร (ใหม่ 7 พ.ย. แทน "ชนะกันสูสีแค่ไหน") | ผู้ชนะแต่ละเขตชนะพรรคไหนมา | แผนภาพการไหล (Sankey) สองคอลัมน์: ซ้าย = พรรคของผู้ชนะ ขวา = พรรคที่ได้อันดับสอง แถบหนาตามจำนวนเขต ไล่สีจากสีพรรคผู้ชนะไปสีพรรคอันดับสอง; ป้ายชื่อพรรคพร้อมจำนวนเขตที่ชนะ/ได้ที่สอง ตัวเลขในแถบที่หนาพอ; พรรคที่มีไม่ถึง 2.5% ของเขตในฝั่งนั้นรวมเป็น "พรรคอื่น" (พรรคที่เลือกแยกเสมอ); เรียงแถบในแต่ละพรรคตามลำดับปลายทางเพื่อลดการตัดกัน; ตัวกรองภูมิภาคเปลี่ยนการไหล | ผู้ใช้ชี้ว่าฮิสโทแกรมส่วนต่างอ่านไม่ออกและไม่มีประโยชน์ (ตัวเลขเขตสูสียังอยู่ในหน้าภาพรวม: KPI "เขตที่ชนะกันไม่ถึง 5%" และรายการ "เขตที่ชนะกันสูสีที่สุด"); หัวข้อใหม่ตอบคำถามที่ผู้ใช้ทั่วไปสนใจและหน้าอื่นไม่บอก — ใครคือคู่แข่งหลัก: ภูมิใจไทยกับประชาชนชิงกันใน 119 จาก 400 เขต (ภูมิใจไทยชนะ 83), ประชาชนได้อันดับสองมากที่สุด 140 เขต, แต่ละภาคต่างกัน (อีสาน ภูมิใจไทย–เพื่อไทย 50 จาก 133 เขต, ใต้ ภูมิใจไทย–ประชาธิปัตย์, กรุงเทพฯ ประชาชนชนะภูมิใจไทย 16 จาก 33); เป็นข้อมูลเชิงหมวด × หมวด ที่มีจำนวน จึงใช้ Sankey ซึ่งไม่ซ้ำกับกราฟอื่นในหน้า (ตารางไขว้แบบฮีตแมปซ้ำกับหน้าภาค); คลิกแถบเลือกเขตชุดนั้น (ชิปบนแถบบน รายชื่อเขต และจำกัดอันดับในแท็บ "ที่สุดของผู้สมัคร" ให้เหลือเฉพาะเขตชุดนั้น) คลิกชื่อพรรคไฮไลต์พรรค; ข้อค้นพบใต้คำถามเปลี่ยนตามภาคและพรรคที่เลือก ("ประชาชน ชนะ 88 เขต ส่วนใหญ่ชนะ ภูมิใจไทย (36) · ได้อันดับสอง 140 เขต ส่วนใหญ่แพ้ ภูมิใจไทย (83)") |
| C ส.ส.เขตกับบัญชีรายชื่อ (ใหม่ 7 พ.ย. แทน "ได้เสียงข้างมากไหม") | แต่ละพรรคได้ ส.ส. มาจากเขตหรือจากบัญชีรายชื่อ | slope chart: เส้นละพรรคจาก % ของ ส.ส.แบ่งเขต 400 ที่นั่ง (แกนซ้าย) ไป % ของ ส.ส.บัญชีรายชื่อ 100 ที่นั่ง (แกนขวา); ป้ายปลายเส้นเป็นจำนวนที่นั่งและ % ("ภูมิใจไทย 173 (43%)" → "19 (19%)") ขยับไม่ให้ทับพร้อมเส้นชี้; พรรคที่ได้ < 10 ที่นั่งรวมเป็นเส้นประ "พรรคอื่น 17 พรรค" (พรรคเล็กที่ถูกเลือกแยกเส้นของตัวเอง); เส้นของพรรคที่นำแต่ละแบบหนากว่า | ผู้ใช้ชี้ว่าเรื่องนี้แปรผกผันระหว่างพรรคอันดับ 1 และ 2 ข้อมูลยืนยัน: ภูมิใจไทย 173 เขต (43%) แต่บัญชีรายชื่อ 19 (19%) ประชาชน 88 เขต (22%) แต่บัญชีรายชื่อ 32 (32%) มากที่สุด; กล้าธรรม 56 → 2 พึ่งเขต ประชาธิปัตย์ 10 → 11 และพรรคเล็กรวม 15 → 20 พึ่งบัญชีรายชื่อ; slope chart ทำให้การสลับอันดับเห็นเป็นเส้นตัดกัน ใช้ % ไม่ใช่จำนวนดิบเพราะสองแบบมีที่นั่งไม่เท่ากัน (จำนวนดิบทำให้ทุกเส้นลาดลงเพราะขนาดชั้น) แต่จำนวนอยู่ในป้าย; บัญชีรายชื่อจัดสรรทั้งประเทศ ตัวกรองภูมิภาคจึงไม่ใช้ (กราฟเสียงข้างมากเดิม — beeswarm 257/400 ไม่ถึงครึ่ง — ถูกนำออก) |
| D อันดับของแต่ละพรรค (ใหม่ 12 พ.ย. ในภาพรวมแทน "รวมเสียงตั้งรัฐบาล") | ผู้สมัครของแต่ละพรรคชนะ ได้ที่สอง หรือที่สาม กี่เขต | แท่งซ้อนแนวนอน หนึ่งแท่งต่อพรรค ยาวเท่าจำนวนเขตที่ส่งผู้สมัคร: ชนะ / ที่สอง / ที่สาม เป็นสีพรรคเข้มเต็ม → จางลงสองขั้น (ความเข้มของสีพรรคเดียวบอกอันดับ ไม่เพิ่มสีใหม่) อันดับ 4 ลงไปเป็นแถบเทาที่บางกว่า เว้นช่องสีพื้น 2 px ระหว่างช่วง; ตัวเลขอยู่ในช่วงที่กว้างพอ; คำอธิบายสีเป็นหมึกกลางเหนือกราฟ (ชนะ · ที่สอง · ที่สาม · อันดับ 4 ลงไป); แสดงพรรคที่ชนะอย่างน้อย 1 เขตหรือติดสามอันดับแรกใน ≥ 2% ของเขต เรียงตามจำนวนเขตที่ชนะ (ภาพย่อแสดงเฉพาะพรรคใหญ่ที่ความสูงพอ); คลิกช่วงเลือกเขตชุดนั้น (เช่น "ประชาชน ได้ที่สอง" 140 เขต — ใช้กับตัวกรองชุดเขตเดียวกับแถบในกราฟ B) คลิกชื่อพรรคไฮไลต์พรรค; ตัวกรองภูมิภาคใช้ได้ | ผู้ใช้ขอกราฟที่สี่ที่ประเภทต่างจากอีกสามกราฟ อ่านง่าย และเกี่ยวข้องกับสามกราฟ: กราฟนี้บอก "ความกว้างของฐานเสียง" ซึ่งอธิบายทั้งสามกราฟ — ประชาชนติดสามอันดับแรก 363 จาก 399 เขตที่ส่ง (91%) แต่ชนะเพียง 88: มีคะแนนเกือบทุกเขตแต่ได้ที่นั่งเขตน้อยกว่าคะแนน (A) เป็นอันดับสองบ่อยที่สุด 140 เขต (B) และจึงได้บัญชีรายชื่อมากที่สุด (C); ภูมิใจไทยชนะ 173 จาก 394 เขตที่ส่ง; กล้าธรรมชนะ 56 แต่อันดับ 4 ลงไปถึง 199 เขต (ฐานเสียงกระจุกเป็นพื้นที่); ประชาธิปัตย์ส่ง 398 เขต ชนะ 10; ข้อมูลเชิงลำดับ (อันดับ 1, 2, 3, 4+) ต่อพรรค จึงใช้แท่งซ้อนเรียงตามลำดับอันดับ ไม่ซ้ำกับกราฟกระจาย Sankey และ slope chart; รอบ 11 พ.ย. เคยไม่เลือกหัวข้อ "อันดับของผู้สมัครแต่ละพรรค" เพราะคิดว่าซ้ำ B แต่ B บอกเฉพาะอันดับหนึ่งกับสองของแต่ละเขต กราฟนี้นับถึงอันดับสามต่อพรรคและบอกจำนวนเขตที่ส่ง จึงตอบเรื่องที่ B ไม่บอก; ข้อค้นพบใต้คำถามบอกพรรคที่ติดสามอันดับแรกมากที่สุดเทียบกับพรรคที่ชนะมากที่สุด หรือผลของพรรคที่ไฮไลต์ |
| รวมเสียงตั้งรัฐบาล (ใหม่ 11 พ.ย.; แท็บของตัวเองและข้อมูลฝ่ายในสภาปัจจุบันตั้งแต่ 12 พ.ย.) | รวมพรรคไหนบ้างถึงจะได้เสียงเกินครึ่งสภา และตอนนี้ใครเป็นรัฐบาล ใครเป็นฝ่ายค้าน | รูปสภาครึ่งวงกลม (hemicycle) 500 จุด หนึ่งจุด = 1 ที่นั่ง สีพรรค; พรรคที่เลือกเป็นจุดทึบเรียงจากซ้าย (เรียงตามจำนวนที่นั่ง) พรรคที่ยังไม่เลือกเป็นจุดจางมีขอบ; ทุกแถวมีจำนวนจุดเป็นเลขคู่ จึงมี 250 จุดอยู่แต่ละฝั่งของเส้นประกลางรูปพอดี: จุดทึบเลยเส้น = ได้เกินครึ่ง (251), จุดทึบหยุดที่เส้นพอดี = 250 ขาด 1; กลางรูปเป็นจำนวนที่นั่งรวมกับ "ขาดอีก N" หรือ "✓ เกินครึ่งแล้ว"; **ใต้รูปสภา** เป็นการ์ดสองใบ "ตอนนี้ใครเป็นรัฐบาล ใครเป็นฝ่ายค้าน": ฝ่ายรัฐบาล 16 พรรค 293 เสียง "เกินครึ่งสภา (251) อยู่ 42 เสียง" และฝ่ายค้าน 5 พรรค 149 เสียง "ไม่ถึงครึ่งสภา ขาดอีก 102 เสียง" แต่ละใบบอกทุกพรรคพร้อมจำนวน ส.ส. (พรรคละ 1 ที่นั่งรวมไว้ท้าย) กดการ์ดแล้วแสดงฝ่ายนั้นในรูปสภา; ใต้การ์ดบอกว่าอีก 58 เสียงไม่อยู่ทั้งสองฝ่าย (กล้าธรรมไม่ได้ร่วมรัฐบาล และถูกปรับออกจากวิปฝ่ายค้านเมื่อ 21 ก.ย. 2569) วันที่ตรวจสอบล่าสุด และลิงก์ที่มา; ความสูงของรูปสภาคำนวณจากความสูงจริงของการ์ดหลังจัดวาง ป้ายเหนือรูปจึงไม่ถูกตัด; หน้าต่างเตี้ย (เช่น 1366 × 650) การ์ดเปลี่ยนเป็นปุ่มสั้น "รัฐบาล 293" "ฝ่ายค้าน 149" เหนือรายชื่อพรรค; การ์ดแคบ (< 540 px) ย้ายจำนวนพรรคลงบรรทัดสถานะ; ข้างรูปเป็นรายชื่อพรรค (ทั้งคำอธิบายสีและปุ่มเพิ่ม/เอาออก รายชื่อยาวเลื่อนในกรอบโดยจางที่ขอบล่าง) และปุ่มล้าง; เปิดมาแสดงฝ่ายรัฐบาล; มุมมองตารางมีคอลัมน์ "ฝ่ายในสภาตอนนี้" และตาราง "ตอนนี้ในสภา" สามแถว | คำถามแรกหลังเลือกตั้งคือใครตั้งรัฐบาลได้ ซึ่งการ์ดพรรคในหน้าภาพรวมบอกจำนวนที่นั่งแต่รวมให้ไม่ได้; ข้อมูลชุดนี้มีเรื่องให้เห็นชัด: ไม่มีพรรคใดถึง 251, ภูมิใจไทย 192 ขาด 59, ภูมิใจไทย + ประชาชน = 312, ภูมิใจไทย + เพื่อไทย = 266, **ภูมิใจไทย + กล้าธรรม = 250 ขาดที่นั่งเดียว**; ส่วนของทั้งหมดเทียบเกณฑ์ปกติใช้แท่งซ้อนกับเส้นเกณฑ์ แต่แท่งกว้าง 500 px แยก 250 กับ 251 ไม่ออก รูปแบบหนึ่งจุดต่อที่นั่งทำให้ที่นั่งเดียวมองเห็นได้ และเป็นรูปที่คนจำได้ว่าคือสภา; ผู้ใช้ต้องการข้อมูลจริงในปัจจุบันแทนเมนู "ลองสูตรสำเร็จ" 7 ชุด (ชุดพรรคที่รวมแล้วเกินครึ่ง) ซึ่งถูกนำออก ส่วนการกดรวมเสียงเองยังอยู่ให้ผู้ใช้ลอง; ฝ่ายในสภาไม่ใช่ผลเลือกตั้ง จึงเก็บแยกในคอลัมน์ `house_side` ของ parties.csv พร้อมวันที่ตรวจสอบและที่มาใน election.csv (`house_*`) แก้ได้เองเมื่อการเมืองเปลี่ยนโดยไม่กระทบตัวเลขอื่น (DATA_EDITING_GUIDE) ตรวจจากรายชื่อพรรคร่วมรัฐบาลคณะรัฐมนตรีคณะที่ 66 (อนุทิน 2) และวิปฝ่ายค้านที่ประกาศ 21 ก.ย. 2569 ณ วันที่ 12 พ.ย. 2569 (DATA_PROVENANCE); จำนวนเสียงนับตามผลเลือกตั้ง ไม่ได้ปรับตามการเปลี่ยนแปลงหลังเลือกตั้ง (เขียนไว้ใต้การ์ดและในหน้าต่างที่มาข้อมูล); ข้อค้นพบใต้คำถามเปลี่ยนตามพรรคที่เลือก ("ฝ่ายรัฐบาลตอนนี้ 16 พรรค รวม 293 ที่นั่ง เกินครึ่งสภาแล้ว มากกว่าที่ต้องใช้ 42 ที่นั่ง · พรรคที่ขาดไม่ได้: ภูมิใจไทย, เพื่อไทย"); เกณฑ์มาจาก `majority` ของชุดข้อมูล; ตัวกรองภูมิภาคไม่ใช้กับกราฟนี้ |
| ภูมิภาค × พรรค (คงไว้) | รูปแบบคะแนนแต่ละภูมิภาค | ฮีตแมป (ตาราง HTML ที่เป็นทั้งกราฟและตาราง) สีเดียวอ่อน→เข้ม สเกลเดียวทั้งตาราง + แถวทั้งประเทศ | สรุปใต้หัวข้อบอกพรรคที่นำแต่ละภาคตามตัวชี้วัดที่เลือก (บัญชีรายชื่อ: ประชาชน 5 ภาค เพื่อไทยอีสาน ประชาธิปัตย์ใต้; ที่นั่ง: ภูมิใจไทย 6 ภาค); สัดส่วน = Σคะแนน ÷ Σบัตรดีชนิดเดียวกัน |
| ที่สุดของผู้สมัคร (ใหม่ 11 พ.ย. แทน "เมืองกับชนบท") | ใครได้คะแนนมากที่สุด ใครชนะขาด ใครชนะเฉียดฉิว | รายการเรียงอันดับ 10/20/50 แถว หนึ่งแถว = ผู้สมัครหนึ่งคน: อันดับ, ภาพผู้สมัคร (42 px), ชื่อ, พรรคกับเขต, คู่แข่งกับคะแนนของทั้งสองคน ("ชนะ … · 36,480 ต่อ 36,214"), แท่งแนวนอนสีพรรคยาวตามค่าที่จัดอันดับ และตัวเลขนั้นที่ปลายขวา; เลือกได้ 5 อันดับ: คะแนนมากที่สุด / ชนะขาดที่สุด / ชนะเฉียดฉิวที่สุด (สองอันดับนี้แท่ง = ส่วนต่างจากอันดับสองเป็น % ของบัตรดีในเขต ซึ่งเป็นเกณฑ์เดียวกับ KPI "เขตที่ชนะกันไม่ถึง 5%" และรายการ "เขตที่ชนะกันสูสีที่สุด" ของหน้าภาพรวม จึงได้เขตเดียวกันเรียงลำดับเดียวกัน โดยมีจำนวนคะแนนที่ห่างกำกับใต้ตัวเลข) / แพ้ทั้งที่ได้คะแนนสูง / ชนะด้วยคะแนนน้อยที่สุด; หัวตารางบอกว่าแท่งและตัวเลขคือค่าอะไร; คลิกแถวเปิดผลทั้งเขต | กราฟอื่นทุกกราฟนับพรรคหรือเขต กราฟนี้เป็นกราฟเดียวที่บอกชื่อคน และใช้ภาพผู้สมัคร 3,489 ภาพที่มีอยู่แล้ว; อันดับคือค่าเดียวต่อหนึ่งคน จึงใช้แท่งเรียงอันดับ (อ่านง่ายที่สุดสำหรับการเทียบขนาด) ไม่ใช้กราฟการกระจายแบบฮิสโทแกรม/beeswarm ที่ผู้ใช้เคยบอกว่าอ่านไม่ออก; ข้อค้นพบใต้คำถามคำนวณจากอันดับบนจอ: ได้คะแนนมากที่สุด 71,153 (เพชรบุรี เขต 3) มากเป็น 3.7 เท่าของผู้ชนะที่ได้น้อยที่สุด (19,458 ภูเก็ต เขต 1), ชนะขาดที่สุด 69.4% ของบัตรดี หรือ 59,415 คะแนน (อุบลราชธานี เขต 10) และครึ่งหนึ่งของ 400 เขตชนะกันเกิน 17.9%, สูสีที่สุด 299 คะแนน หรือ 0.32% (นครราชสีมา เขต 3) และ 8 เขตชนะกันไม่ถึง 1%, ผู้แพ้ที่คะแนนสูงสุดได้ 43,544 (ประจวบคีรีขันธ์ เขต 1) มากกว่าผู้ชนะใน 235 จาก 400 เขต; จัดอันดับภายในขอบเขตที่เลือก: ตัวกรองภูมิภาค จังหวัด ชุดเขตที่เลือกจากกราฟ B และเฉพาะผู้สมัครของพรรคที่ไฮไลต์ (ข้อค้นพบต่อท้ายด้วย "เฉพาะ …"); เขตที่ยังไม่มีผู้ชนะไม่ถูกจัดอันดับ; คะแนนที่ห่างกันน้อยคือการแข่งขันสูสี ไม่ใช่หลักฐานของความผิดปกติ (เขียนไว้ท้ายการ์ด) |
| เปรียบเทียบเขตที่สนใจ (ออกแบบใหม่ 12 พ.ย.) | เขตที่ผู้ใช้เลือกต่างกันอย่างไร | ตารางเทียบข้างกัน หนึ่งคอลัมน์ต่อหนึ่งเขต (สูงสุด 3 เขต) ข้อเท็จจริงเดียวกันอยู่แถวเดียวกัน 6 แถว: ผู้ชนะ (ภาพ ชื่อ พรรค คะแนน), ชนะห่างอันดับสอง (% ของบัตรดี คะแนน แท่ง ป้าย "สูสีที่สุด" และชื่ออันดับสอง), ผู้สมัคร 3 อันดับแรก, บัตรเลือกพรรค 3 อันดับแรก (บอกว่าพรรคที่นำตรงกับพรรคของผู้ชนะหรือไม่), ผู้มาใช้สิทธิ (แท่งพร้อมขีดค่าทั้งประเทศ และป้าย "มากที่สุด"), บัตรเสียกับไม่เลือกผู้ใด; แท่งในแถวเดียวกันใช้สเกลเดียวกัน (สองแถวคะแนนใช้สเกลร่วม); หัวคอลัมน์บอกอำเภอ/เขตในเขตนั้น ปุ่ม "ดูผลทั้งเขต" และปุ่ม × เอาออก; ข้างตารางเป็นกล่อง "เพิ่มเขต" ที่มีช่องค้นหา (ชื่ออำเภอ ตำบล เขต หรือชื่อผู้สมัคร กรองระหว่างพิมพ์ Enter เพิ่มผลแรก) และเมนูเลือกจังหวัดที่แสดงทุกเขตของจังหวัดพร้อมพื้นที่และพรรคที่ชนะ; ยังไม่เลือกเลย: ช่องว่างของเขตที่ 2 และ 3 แสดงแถวที่จะเปรียบเทียบ; ครบ 3 เขตกล่องเพิ่มเขตหายไป | เดิมผู้ใช้ไม่เข้าใจว่าเมนูสองช่องและแท่งห้าแท่งต่อตัวชี้วัดใช้อย่างไร และคนส่วนใหญ่ไม่รู้เลขเขตของตัวเอง จึงค้นหาด้วยชื่อสถานที่หรือผู้สมัครได้ และทุกตัวเลือกบอกพื้นที่ในเขต; ตารางข้างกันอ่านเทียบด้วยการมองตามแถว (แบบตารางเทียบสินค้าที่คนทั่วไปคุ้น) และมีข้อมูลที่เป็นประโยชน์กว่าเดิม (คู่แข่ง คะแนนพรรคกับผู้สมัคร การใช้สิทธิเทียบทั้งประเทศ); ข้อค้นพบใต้คำถามบอกพรรคของผู้ชนะในชุดที่เลือกและเขตที่สูสี/ขาดที่สุด; ผู้ใช้เลือกเองทุกเขต (ไม่มีการเลือกให้อัตโนมัติ); หน้าต่างแคบ (< 820 px) กล่องเพิ่มเขตย้ายขึ้นด้านบน; บนโทรศัพท์แต่ละแถวเป็นกลุ่มที่มีทุกเขตเรียงลงมา |

ใต้คำถามของทุกการ์ดเป็น **ข้อค้นพบหลัก** ที่คำนวณจากข้อมูลบนจอ (เปลี่ยนตามตัวกรองภูมิภาค พรรค และมุมมอง) ส่วนวิธีอ่านและนิยามย้ายไปท้ายการ์ด ภาพย่อในแท็บแรกแสดงข้อค้นพบเดียวกันแบบสั้นใต้ชื่อกราฟ (เช่น "ประชาชน ติดสามอันดับแรก 363 เขต ชนะ 88") ทุกกราฟ (ยกเว้นฮีตแมปและเปรียบเทียบซึ่งเป็นตารางอยู่แล้ว) มีปุ่ม **ดูเป็นตาราง** ในกราฟที่ขยายแล้ว เป็นมุมมองคู่ที่อ่านด้วย screen reader ได้

ตัวอักษร A–D ใช้อ้างถึงกราฟในเอกสารนี้เท่านั้น บนหน้าเว็บแท็บใช้ชื่อที่บอกเนื้อหา: เดสก์ท็อป 5 แท็บ "ภาพรวม 4 กราฟ / คะแนนแต่ละภาค / ที่สุดของผู้สมัคร / รวมเสียงตั้งรัฐบาล / เปรียบเทียบเขตที่สนใจ" ภาพย่อในแท็บแรกชื่อ "คะแนนกับที่นั่ง (A) / ใครชนะใคร (B) / ส.ส.เขตกับบัญชีรายชื่อ (C) / อันดับของแต่ละพรรค (D)"; โทรศัพท์แสดงทั้ง 8 กราฟทีละกราฟตามลำดับ A, B, C, D, คะแนนแต่ละภาค, ที่สุดของผู้สมัคร, รวมเสียงตั้งรัฐบาล, เปรียบเทียบเขตที่สนใจ (รวมเสียงตั้งรัฐบาลเปิดได้จากแท็บ "สภา" ในแถบล่างด้วย) หัวการ์ดเป็นคำถามที่กราฟตอบ

## ภาษาภาพ ตัวอักษร และสี
- ฟอนต์เดียวทั้งระบบคือ Noto Sans Thai (Google, OFL; เปลี่ยนจาก Anuphan เมื่อ 3 พ.ย. 2569 โดยคงขนาด น้ำหนัก ระยะบรรทัดเดิมทั้งหมด) ฟอนต์ไทยไม่มีหัว ฝังในเว็บเพื่อใช้ออฟไลน์ สเกล 12/13/14/16/17/22/28/34px น้ำหนัก 400 เนื้อหา 500 ป้าย 600 หัวข้อ 700 ตัวเลขใหญ่ ไม่เพิ่มระยะห่างตัวอักษรภาษาไทย และไม่ใช้ตัวพิมพ์ใหญ่ทั้งคำกับป้าย
- **ขนาดตัวอักษรตามขนาดจอเดสก์ท็อป** (13 พ.ย. 2569 ตามผู้ใช้ "รู้สึกว่าตัวอักษรยังเล็กเกินไปสำหรับ Desktop"): ขนาดตัวอักษร 11–17 px ทุกจุดเป็นขั้นของสเกลเดียว (`--f11` … `--f17` ใน `e69.css` ตัวเลขในชื่อคือขนาดในสเกลเล็ก) จอเดสก์ท็อปที่มีที่พอเปลี่ยนทั้งชุดเป็นขนาดที่ใหญ่ขึ้นสามขั้น: ตั้งแต่ 1366 × 640 (โน้ตบุ๊ก 1366 × 768) ข้อความเล็ก (≤ 14 px) +1 px ขนาดกลาง (14.5–15.5) +0.5 หัวข้อเท่าเดิม; ตั้งแต่ 1440 × 700 (เช่น 1920 × 1080 ที่ตั้งซูม 125% ซึ่งเปิดเป็น 1536 × 730, หรือ 1440 × 900) +1.5 / +1 / +0.5; ตั้งแต่ 1800 × 900 (1920 × 1080) +2.5 / +2 / +1 — ข้อความเล็กขยายมากที่สุดเพราะเป็นจุดที่อ่านยาก หัวข้อใหญ่พออยู่แล้ว; ตัวอักษรที่วาดด้วยสคริปต์ (ป้ายแกน ชื่อพรรค ตัวเลขในกราฟ ชื่อจังหวัดบนแผนที่ เลขเขต) ขยายตามขั้นเดียวกัน (`typeUp()` ใน `e69-app.js`) พร้อมเพิ่มระยะขอบกราฟและระยะห่างระหว่างป้าย; ชื่อจังหวัดยังไม่ใหญ่เกินช่อง; แถบข้างกว้างขึ้นตามขั้น (264 → 280 → 290 → 306 px) ให้ป้ายค้นหาและเมนูอยู่บรรทัดเดียว; หน้าต่างที่สูงไม่ถึง 720 px ลดระยะห่างในแถบข้างให้เมนู ตัวกรอง และ Clear All พอดีโดยไม่ต้องเลื่อน; ชื่อพรรคบนการ์ดพรรคถูกจำกัดไม่ให้เกินความกว้างการ์ด (คำนวณจากความกว้างการ์ดด้วย container query จึง "รวมไทยสร้างชาติ" อยู่บรรทัดเดียว); หัวข้อแผนที่ระดับประเทศอยู่บรรทัดเดียว เมนูสีข้างหัวข้อยอมแคบลงแทน; tooltip จังหวัด tooltip กราฟ และหน้าต่างที่มาข้อมูลกว้างขึ้นตามขั้น; ป้ายสถิติที่มีวงเล็บ เช่น "ไม่เลือกผู้ใด (แบบแบ่งเขต)" ตัดบรรทัดก่อนวงเล็บ ไม่ตัดกลางคำ; จอกว้างไม่ถึง 1366 px (หรือเตี้ยกว่า 640 px) คงขนาดเดิม เพราะเลย์เอาต์สามคอลัมน์ไม่มีที่ให้ขยายโดยไม่ทำให้ตัดบรรทัดหรือต้องเลื่อน; โทรศัพท์คงขนาดของตัวเอง; ตรวจที่ 9 ขนาดจอ (1024 × 768 ถึง 2560 × 1300) ทั้งภาษาไทยและอังกฤษ 14 สถานะต่อขนาด: ไม่มีหน้าใดหรือแถบข้างต้องเลื่อน ไม่ล้นแนวนอน ไม่มีข้อความถูกตัดด้วย … ตัวอักษรในกราฟไม่เกินขอบกราฟ และนับป้ายที่ตัดบรรทัดเพิ่มเทียบกับก่อนปรับ (เหลือเฉพาะบรรทัดหมายเหตุใต้ตัวเลข KPI บนจอ 1920 ซึ่งมีที่ว่างแนวตั้งพอ)
- อัตลักษณ์ Election 69 (ปรับ 6 พ.ย. 2569): โลโก้คือสัญลักษณ์ "บัตรเลือกตั้งที่มีกากบาทกำลังหย่อนลงหีบ" บนสี่เหลี่ยมมนสีน้ำทะเลลึก ช่องหีบเป็นสีฟ้า #00A3E0 กากบาทสีแดง คู่กับคำ ELECTION**69** หนาขึ้น (800) และ 69 สีแดงธงชาติ; มีแสงสีฟ้าพาดผ่านสัญลักษณ์และตัวอักษรจากซ้ายไปขวา แล้วพาดกลับในอีกช่วง (รอบละ 9 วินาที) ชี้ที่โลโก้แล้วบัตรจมลงหีบ; ไอคอนแท็บ (favicon) เป็นสัญลักษณ์เดียวกัน; ขนาดกล่องโลโก้สูง 51px เท่าเดิม เมนูด้านล่างไม่ขยับ
- สีหลัก (ปรับ 6 พ.ย. 2569 ตามผู้ใช้ "เอาฟ้าสี #00A3E0 ที่ทำมาดูน้ำเงิน เดี๋ยวจะดูว่าเชียร์ภูมิใจไทย"): ทุกเฉดฟ้าในหน้าเว็บมาจาก #00A3E0 (OKLCH hue 234°) ที่ความสว่างต่างกัน พื้นหลัง #dff3fe ทะเลแผนที่ #d5effe ลิงก์ #0175a2 (5.2:1); หมึกและสถานะที่เลือก (เช่นปุ่ม "ภาพรวม") เปลี่ยนจากกรมท่าอมม่วง #1e1b3a เป็นสีน้ำทะเลลึก #102631 / #0c2a39 ที่ความสดต่ำ ห่างจากกรมท่าของภูมิใจไทย (#0F1E64 hue 268° chroma 0.12) ทั้งเฉดและความสด; ธีมมืดเป็นน้ำเงินทะเลเข้มเฉดเดียวกัน; สีฟ้าสดใช้เฉพาะเส้นเล็ก แสง และช่องหีบในโลโก้ ไม่ใช้เป็นพื้นใหญ่ เพราะ #00A3E0 ใกล้สีประชาธิปัตย์ (#00AEEF) สีพรรคยังเป็นของพรรคตามเดิม
- **แสงสีบนแผนที่** (6 พ.ย. 2569 ตามผู้ใช้ "ตรงแผนที่พวกแสงสียังไม่สวย ให้มีลูกเล่นเพิ่ม") หลักคือแสงและเงาอยู่ "รอบ" สีข้อมูล ไม่เปลี่ยนสีพรรคหรือสเกลสีของช่องเลย:
  - ทะเลมีชีวิต: แสงนุ่มสองดวงลอยช้า ๆ ใต้แผนที่ (26 วินาทีต่อเที่ยว) ธีมสว่างเหมือนแสงแดดบนน้ำ ธีมมืดเป็นแสงฟ้าเรืองจาง ๆ; ขอบทะเลมีเส้นฟ้าบาง ๆ
  - ช่องลอยจากทะเล: ใต้ทุกช่องมีเงาสองชั้นเลื่อนลงเล็กน้อย (สำเนารูปเดียวกัน ไม่ใช้ filter จึงเบา) เห็นเป็นขอบเงาที่ช่องติดทะเล; เงาจางตามตัวกรองภูมิภาค และซ่อนระหว่างกล้องบินเข้า-ออก; แผนที่รายเขตมีเงาแบบเดียวกันที่ค่อย ๆ ขึ้นหลังเขตบานเสร็จ
  - แถบแสงพาด: แถบแสงขาวเฉียงพาดผ่านช่องทั้งประเทศ (ถูกตัดตามรูปช่อง ทะเลไม่เปลี่ยน) ครั้งแรกราว 1 วินาทีหลังแผนที่ขึ้น แล้วทุก 15 วินาที; เปิดจังหวัดแล้วแถบแสงพาดผ่านเขตของจังหวัดนั้น
  - เปิดหน้าครั้งแรก: จังหวัดสว่างขึ้นทีละช่องจากกรุงเทพฯ กระจายออกไป (≈1.2 วินาที) ครั้งเดียวต่อการเปิดหน้า
  - ช่องที่ชี้ส่องแสง (ปรับ 7 พ.ย. 2569 ตามผู้ใช้ "ไม่เอาที่เอาเมาส์จ่อแล้วที่เหลือมืดลง เอาช่องที่จ่อสว่างขึ้นเหมือนส่องแสง"): ช่องหรือเขตที่ชี้สว่างและสดขึ้นเหมือนมีแสงจากข้างใน (สว่างขึ้น 22% ธีมมืด 34%) เส้นขอบเรืองแสงและแสงค่อย ๆ หายใจเข้าออก (1.4 วินาที) ช่องอื่นทุกช่องคงสีเต็มเหมือนเดิม; ใช้ filter บนรูปเท่านั้น ค่าสีจริง (fill) และป้ายชื่อไม่เปลี่ยน; จังหวัดที่ปักหมุดมีเส้นขอบเรืองแสง
  - ตรวจ: 60 fps ขณะแถบแสงพาดและขณะชี้ไล่ช่อง (Chrome headless แบบ software; มีสะดุดครั้งเดียว ~67 ms ตอนชี้ครั้งแรกซึ่งเป็นตอนสร้าง tooltip ครั้งแรก); ผู้ที่ตั้งค่าลดการเคลื่อนไหวไม่มีแอนิเมชันบนแผนที่เลย; e2e ตรวจว่ามีเงา 154 รูป แถบแสงและแสงในทะเลทำงาน ชี้แล้วมีเพียงช่องนั้นที่สว่างขึ้น และสีข้อมูลไม่เปลี่ยน
- **แสงตามเมาส์** (6 พ.ย. 2569): เมนู แท็บ ปุ่ม ชิป ไทล์ KPI และการ์ดพรรค มีแสงนุ่ม ๆ ตามตำแหน่งเมาส์และค่อย ๆ จางเข้าออก บนปุ่มสีเข้มที่เลือกอยู่ (เช่น "ภาพรวม") เป็นแสงฟ้าสว่าง บนการ์ดพรรคเป็นสีของพรรคนั้น เฉพาะเมาส์และปากกา (ไม่มีบนจอสัมผัส) อัปเดตไม่เกินหนึ่งครั้งต่อเฟรม ไม่มีเมื่อผู้ใช้ตั้งค่าลดการเคลื่อนไหว
- ปุ่มภาษาเป็นธงชาติไทยและสหราชอาณาจักร (SVG) ที่มุมขวาบน ธงที่ไม่ได้เลือกจะจางลง
- ปุ่มอัปเดตข้อมูลเป็นไอคอนลูกศรวน (Lucide refresh-cw) ทางซ้ายของธง ข้างกันมีป้ายเล็ก "อัปเดตล่าสุด" กับเวลาที่โหลดข้อมูล ระหว่างโหลดไอคอนหมุน ผลการอัปเดตแสดงเป็นป้ายลอยใต้ปุ่ม (ไม่ดันแถบบน) แล้วหายเอง บนมือถือ (≤560px) ปุ่มกับเวลาเป็นแถวเล็กใต้ธง จึงไม่กินพื้นที่หัวข้อ
- สีพรรคเป็นสีตัวตนจากชุดข้อมูลเดิม พรรคสีน้ำเงินเข้มหลายพรรค (ภูมิใจไทย, พลังประชารัฐ, รวมไทยสร้างชาติ) ใกล้กัน จึงมีชื่อพรรคกำกับใน legend, tooltip, ตารางเสมอ
- สเกลลำดับ (sequential) ใช้สีเดียว อ่อน→เข้ม; legend บอกช่วงค่าจริง โหมดพรรคใช้สีพรรคนั้น
- ปริมาณที่ไม่ใช่ของพรรคใดใช้สองชุดสี (`RAMPS` ใน `dist/js/e69-app.js`): เขียวหัวเป็ด (teal) เป็นสีหลัก ใช้กับแผนที่อัตราการใช้สิทธิ (จังหวัดและรายเขต) และฮีตแมป "คะแนนแต่ละภาค" ในหน้าวิเคราะห์; ชมพูกุหลาบ→ม่วงแดงเข้ม (rose) สงวนไว้ให้แผนที่สัดส่วนบัตรเสีย (เปลี่ยนจาก Blues/Oranges เมื่อ 4 พ.ย. 2569; ฮีตแมปเคยเป็น Blues ทำให้ช่องของทุกพรรค รวมถึงคอลัมน์ประชาชน ดูเป็นสีภูมิใจไทย) เหตุผล: สีที่บอกปริมาณต้องไม่ซ้ำสีที่บอกตัวตนพรรค Blues เดิมผ่านสีพลังประชารัฐ (ระยะสี OKLab ΔE 1.2) และใกล้ภูมิใจไทย (9.4) Oranges เดิมผ่านสีประชาชนพอดี (0.5) เฉดใหม่อยู่ในช่องว่างกว้างที่สุดระหว่างสีของ 22 พรรคที่ได้ที่นั่ง: teal ระหว่างเขียวกล้าธรรมกับฟ้าประชาธิปัตย์ ห่างพรรคที่ได้ ≥ 5 ที่นั่งอย่างน้อย ΔE 10.5; rose ระหว่างม่วงไทยสร้างไทยกับแดงเพื่อไทย ห่างอย่างน้อย 14.7 (จำลองตาบอดสีแดง-เขียวแล้วยังห่าง ≥ 9.0 และ ≥ 6.5 ตามลำดับ ซึ่งมี legend และตัวเลขบนช่องกำกับอยู่แล้ว) แต่ละขั้นคงความสว่างเท่าขั้นเดิม (ต่าง ≤ 0.002 OKLab L) ความเข้มจึงบอกค่าเหมือนเดิมและสีตัวอักษรบนช่องไม่เปลี่ยน; วงล้อสีมีช่องว่างจากสีพรรคที่ได้ที่นั่งเพียงสองช่วงนี้ ฮีตแมปจึงใช้ teal ร่วมกับแผนที่แทนการเพิ่มเฉดที่สาม
- ข้อความใช้สีหมึกเสมอ ไม่ใช้สีพรรคกับตัวอักษร
- **ธีมสว่าง/มืด** (6 พ.ย. 2569): ค่าเริ่มต้นตามการตั้งค่าของเครื่องผู้ใช้ (`prefers-color-scheme`) และเปลี่ยนตามทันทีถ้าผู้ใช้สลับโหมดของเครื่องระหว่างเปิดหน้า
  - ปุ่มอยู่มุมขวาบน ติดทางซ้ายของธงภาษา เพราะทั้งสองเป็นการตั้งค่าการแสดงผลของผู้อ่าน และเป็นตำแหน่งที่ผู้ใช้เว็บคุ้นที่สุด ส่วนปุ่มอัปเดตข้อมูลซึ่งเป็นเรื่องของข้อมูลแยกไว้ทางซ้าย
  - รูปแบบเป็นปุ่มไอคอนเดียว แสดงธีมที่เห็นอยู่ (ดวงอาทิตย์/พระจันทร์) กดแล้วเปิดเมนูสามตัวเลือก "ตามระบบของเครื่อง / สว่าง / มืด" ไม่ใช้สวิตช์สองสถานะ เพราะสวิตช์ทำให้กลับไปค่า "ตามเครื่อง" ไม่ได้ ใช้ลูกศรขึ้นลง Enter และ Esc ได้ ชื่อปุ่ม (title/aria) บอกค่าปัจจุบัน เช่น "ธีมสี: ตามระบบของเครื่อง (มืด)"
  - เลือกสว่างหรือมืดแล้วเบราว์เซอร์นั้นจำไว้ (localStorage `e69-theme`) กลับไป "ตามระบบของเครื่อง" จะลบค่าที่จำ สคริปต์เล็กใน `<head>` ตั้งธีมก่อนวาดหน้าแรก จึงไม่กะพริบเป็นธีมผิด
  - บนมือถือ (≤560px) ไอคอนธีมอยู่ในแถวเล็กใต้ธงข้างปุ่มอัปเดต แถบบนจึงไม่สูงขึ้น ที่ 900–1279px ระยะห่างในแถบบนแคบลงเล็กน้อย เพื่อให้คำบรรยายใต้หัวข้อยังอยู่บรรทัดเดียวเมื่อมีชิปพรรคหรือจังหวัด และถ้าชิปยาวจนต้องตัดบรรทัดจะตัดให้สองบรรทัดยาวพอกัน
  - ธีมมืดมีค่าสีของตัวเอง (`:root[data-theme=dark]` ใน `e69.css` และ `PALETTE.dark` ใน `e69-app.js`) ไม่ได้กลับสีอัตโนมัติ: พื้น #0a111d พื้นผิว #131a28 ตัวอักษร #e6ecf6 (14.7:1) ตัวรอง #94a0b8 (6.6:1) ลิงก์ #8ea0ff (7.2:1) "69" แดง #ef5468 (5.1:1) (ค่ารอบตกแต่ง 6 พ.ย.; เดิมพื้นผิว #171b24 ความสว่างเท่ากัน) สถานะที่เลือกใช้สีกลับด้านเป็นพื้นอ่อนตัวอักษรเข้ม
  - สีพรรคในธีมมืด: สีเข้ม (กรมท่า ม่วง น้ำตาล) ถูกยกความสว่างตามสัดส่วน OKLCH `L' = max(L, 0.43 + 0.33L)` คงเฉดสี ลดความสดเท่าที่จำเป็น สีที่สว่างอยู่แล้วไม่เปลี่ยน ลำดับความสว่างของพรรคจึงเหมือนเดิม ตรวจด้วยตัวตรวจชุดสีของ dataviz skill: ทั้ง 10 พรรคใหญ่ตัดกับพื้นมืด ≥ 3:1 (บนพื้นขาวมี 4 สีต่ำกว่า 3:1) คู่ที่ใกล้ที่สุดยังเป็นสองพรรคสีกรมท่าเหมือนในสีต้นฉบับ (ΔE 5.2 → 5.0) ตัวตรวจยังให้ไม่ผ่านทั้งสองธีมด้วยเหตุผลเดียวกัน เพราะเป็นสีประจำพรรคที่กำหนดมา ไม่ใช่ชุดสีที่ออกแบบ จึงมีชื่อพรรคกำกับเสมอ
  - สเกลปริมาณในธีมมืดกลับจุดยึด: ค่าน้อยกลืนกับพื้นแผนที่ ค่ามากสว่าง เขียวหัวเป็ดกับชมพูกุหลาบเว้นขั้นความสว่างเท่าชุดสว่าง (OKLCH 0.32–0.86) สเกลของพรรค (ที่นั่ง สัดส่วนคะแนน) ไล่จากพื้นช่องมืดผ่านสีพรรคขึ้นไปถึงสีพรรคที่สว่างระดับ 0.86 โดยสีพรรควางตามความสว่างของมันเอง เพราะถ้าจบที่สีพรรค สีกรมท่าจะทำให้ทุกจังหวัดมืดและแยกกันไม่ออก
  - ตรวจแล้วว่าธีมสว่างเหมือนเดิมทุกพิกเซลนอกแถบบน ทั้ง 94 สถานะใน 7 ขนาดจอ
- **บรรยากาศและแสงเงา** (6 พ.ย. 2569 ตามคำขอ "ขาวเกินไป อยากมีฟ้าอ่อนบ้าง มีแสงเงาเล็กน้อย คงความมินิมอลและเลย์เอาต์เดิม") หลักคือสีฟ้าอยู่กับ "บรรยากาศ" ส่วนการ์ดที่มีข้อมูลยังขาว/เรียบเหมือนเดิม และแสงขยับเฉพาะเมื่อผู้ใช้เลือกอะไร
  - สีฟ้าอ่อน: พื้นหลัง (รอบแรก #e5eefa ฟ้าอมม่วง; รอบถัดมาเปลี่ยนเป็นเฉดของ #00A3E0 คือ #dff3fe ตามข้อถัดไป), แถบด้านข้างและแถบบนโปร่งแสงให้สีฟ้าด้านหลังผ่านมา (ขาว 50% / ธีมมืด 74%), ทะเลรอบแผนที่หกเหลี่ยมเป็นฟ้าอ่อนไล่จากกลางที่สว่าง (เชื่อมกับความหมาย "ทะเล" ของแผนที่) ธีมมืดเป็นน้ำเงินลึก; เส้นขอบ พื้นช่องเลือก/วางเมาส์ และราวแท่งกราฟเป็นเทาอมฟ้า; การ์ดธีมมืด #0b1a23 (ตัวอักษรตัดกัน 15:1)
  - แสงพื้นหลัง: แสงนุ่มสามดวง (ฟ้า ฟ้าอมเขียว ฟ้าคราม) เลื่อนช้ามาก 42 วินาทีต่อเที่ยว อยู่หลังทุกอย่าง เห็นได้เฉพาะช่องว่างระหว่างการ์ดและผ่านแถบด้านข้าง/บน ไม่ทับข้อมูล
  - เงา: การ์ดมีเงานุ่มบาง ๆ ย้อมสีกรมท่า (ธีมมืดมีเส้นแสงจาง ๆ ที่ขอบบนการ์ด); เงาไม่เปลี่ยนขนาดกล่องใด ๆ
  - แสงตอบผู้ใช้: ปุ่มไอคอน ปุ่มรีเซ็ต ปุ่มคำอธิบายสีมีวงแสงฟ้าจาง ๆ เมื่อชี้, Clear All มีวงสีแดงจาง, ช่องค้นหาและ select มีแสงรอบเมื่อโฟกัส (เส้นโฟกัสเดิมยังอยู่), จังหวัดที่ชี้มีแสงเรืองรอบเส้นขอบ, การ์ดพรรคที่ชี้มีเงาสีของพรรคนั้น
  - แสงยืนยันการเลือก: แถบแสงเฉียงวิ่งผ่านครั้งเดียว (1 วินาที) บนรายการเมนูของหน้าที่เปิดและบนการ์ดพรรคที่เพิ่งเลือก; เมนูถูกปรับในที่ (`morph`) แสงจึงไม่เล่นซ้ำทุกครั้งที่หน้าวาดใหม่ ตรวจแล้วว่าไม่เล่นเมื่อเปิดจังหวัด เปลี่ยนภาษา หรือเปลี่ยนแท็บ; สถานะที่เลือก (เมนู แท็บ ปุ่มแบ่งส่วน) ไล่เฉดบนลงล่างเล็กน้อยพร้อมเงาใต้
  - ผู้ที่ตั้งค่าลดการเคลื่อนไหว: ไม่มีแอนิเมชันใดเล่น (รวมแสงพื้นหลังและแถบแสง)
  - ความคมชัด: ข้อความรองบนแถบโปร่งแสงใช้เทาเข้มขึ้น (#5d5b75) จึงตัดกับพื้นหลังที่สว่างที่สุดของแสงที่เลื่อนได้ ≥ 5.46:1 (ธีมมืด ≥ 6.54:1 วัดห้าจุดตลอดรอบ 42 วินาที); ป้ายในช่องสถิติที่ไฮไลต์เปลี่ยนเป็นสีหมึกรอง (เดิม 4.2:1)
  - เลย์เอาต์ไม่เปลี่ยน: เทียบตำแหน่งและขนาดทุกองค์ประกอบ 94 สถานะ 7 ขนาดจอ ก่อน-หลัง ตรงกันทั้งหมด ทั้งธีมสว่างและธีมมืด (ภาพเทียบ `verification/decoration-before-after-1440.png`)
- ความเรียบร้อยของตัวอักษร: ตัวเลขในช่องตาราง/ฮีตแมปอยู่กลางช่องทุกแถว; ส่วนเดียวกันของการ์ดที่วางเคียงกันอยู่ระดับเดียวกัน (ตัวเลข KPI แถบสีการ์ดพรรค); ป้ายกับตัวควบคุมของมันขึ้นบรรทัดใหม่ด้วยกันเสมอ; ไม่ตัดบรรทัดกลางชื่อคน ชื่อพรรค วันที่ หรือระหว่างตัวเลขกับหน่วย (คลาส `.nw`); ลิงก์ท้ายกราฟอยู่บรรทัดเดียวกับข้อความบรรทัดสุดท้าย
- ป้ายชื่อจังหวัดบนแผนที่: ภาษาไทยตัดคำตามตาราง BREAKS ขนาดอย่างน้อย 8.5 px; ภาษาอังกฤษวัดความกว้างแต่ละบรรทัดกับรูปหกเหลี่ยมจริง (แคบลงที่ยอดบน-ล่าง) ตัดพยางค์ด้วยยัติภังค์เฉพาะที่จำเป็น และลดได้ถึง 7 px บนช่องเล็ก

## Responsive
- ≥1280px: shell เต็มจอ แผนที่สูงเต็มคอลัมน์ซ้าย, ขวา = KPI → การ์ดพรรค → แผงบริบท (เลื่อนในกรอบ) เมื่อปักหมุดจังหวัด การ์ดพรรคย่อเป็นแถบเลื่อนแนวนอน (ยังมีภาพ) เพื่อให้แผงรายละเอียดสูงขึ้น
- 900–1279px: KPI/การ์ดเต็มกว้าง แผนที่กับแผงบริบทเคียงกัน
- ≥900px ทั้งหน้าไม่เลื่อน แผงย่อยเลื่อนในตัว แผงสภา 500 ที่นั่งล็อกไม่ให้เลื่อนซ้ายขวา; แท็บหน้าวิเคราะห์ 5 แท็บไม่ล้นจอ (ที่ 900–1139 px ระยะในแท็บแคบลงให้อยู่แถวเดียว); แท็บแรกเป็นภาพย่อ 4 กราฟในตาราง 2 × 2 ทุกขนาดจอเดสก์ท็อปตั้งแต่ 900 × 600 คลิกเพื่อขยาย; ขนาดตัวอักษรขยายตามขนาดจอ (ดู "ขนาดตัวอักษรตามขนาดจอเดสก์ท็อป")
- <900px และโทรศัพท์ที่ถือแนวนอน: เลย์เอาต์โทรศัพท์ (รายละเอียดใน `MOBILE_UX_REDESIGN.md`): แถบบนมีปุ่มเมนูที่มุมซ้ายบน (เปิดแถบด้านข้างที่มีธีมสี การอัปเดตข้อมูล และที่มาข้อมูลกับวิธีอ่าน) ชื่อหน้า และธงภาษา; แถบล่าง 5 แท็บ สรุปผล / แผนที่ / วิเคราะห์ / สภา / ค้นหา/กรอง (ค้นหาและตัวกรองอยู่แผงเดียวกัน); แผนที่ประเทศไทยมีแว่นขยายแบบ focus + context เมื่อแตะค้างแล้วเลื่อนนิ้ว; แตะจังหวัดเปิดแผนที่รายเขตเหนือแผงรายละเอียด; หน้าวิเคราะห์แสดงทีละกราฟ (8 กราฟ)
- ปุ่มควบคุมสูง 40–46px บนเดสก์ท็อป, เป้าสัมผัส ≥ 44px สำหรับรายการหลัก
