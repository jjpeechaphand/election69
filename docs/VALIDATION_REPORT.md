ข้อบกพร่องที่พบระหว่างทดสอบและแก้แล้ว: (1) `d3.raise()` ย้ายช่องที่มีโฟกัสทำให้คีย์บอร์ดหลุด → เปลี่ยนเป็นเส้นขอบซ้อนทับ; (2) tooltip บังช่องข้างเคียง → ย้ายไปวางข้างการ์ดแผนที่ (รอบล่าสุดเปลี่ยนเป็นตามเมาส์ตามคำขอผู้ใช้ และแก้การบังด้วยข้อ 7); (3) ป้ายภาษาไทยถูกตัดกลางพยางค์ (เช่น "เชีย/งใหม่") → ใช้ตารางขอบคำที่ตรวจแล้ว; (4) legend บังช่องฝั่งตะวันออก → legend สองคอลัมน์มุมอ่าว; (5) แผงรายละเอียดในหน้าวิเคราะห์ยืดความสูงกราฟ → ทำเป็นแผงติดขอบเลื่อนในตัว; (6) หลัง Escape tooltip เด้งกลับเพราะเบราว์เซอร์ส่ง pointerover ให้ช่องที่อยู่ใต้เมาส์ → ปิดค้างจนกว่าเมาส์จะขยับ ≥ 8px; (7) เลื่อนเมาส์เร็วแล้วตกลงบน tooltip ที่ตามมา ทำให้บังแผนที่ → tooltip ไม่รับเมาส์ระหว่างตาม รับเมื่อหยุดแล้ว; (8) Clear All ขณะไม่ได้เปิดจังหวัดทำให้การซูมครั้งถัดไปไม่มีแอนิเมชัน → ใช้สถานะ "สลับทันที" ครั้งเดียวทุกครั้งที่วาดแผนที่; (9) หลังรีเซ็ตช่องของจังหวัดเดิมค้าง opacity 1 แบบ inline ทับการจางตามภูมิภาค → ล้างเมื่อทรานสิชันจบ; (10) แท็บที่ 7 ของหน้าวิเคราะห์ล้นจอที่ 1366px → ตัดเป็นสองแถวสมดุล 4 + 3; (11) เลือกพรรคขณะดูแผนที่รายเขต คำอธิบายสีใต้แผนที่สูงเปลี่ยน แผนที่ถูกสร้างใหม่และบางเขตเป็นสีดำชั่วขณะ (SVG ที่ยังไม่มี fill) → วาดครั้งเดียวต่อจังหวัด ขนาดเปลี่ยนเล็กน้อยใช้ viewBox และไม่ทำทรานสิชันจากค่าว่าง; (12) ทรานสิชันจบด้วยสี `rgb(...)` แทน `#hex` เดิม → ตั้งค่าสีเดิมเมื่อจบ; (13) ที่ 1920px การจำกัดความกว้างคำบรรยายใต้ภาพทำให้การ์ดสูงขึ้น 14px → กลับไปใช้ความกว้างเดิมและลดกรอบภาพเป็น 44%

รอบเครดิต/ภาพ/การเคลื่อนไหว (3 พ.ย. 2569): e2e เพิ่มการตรวจ — เครดิตอยู่นอกกรอบแผนที่และใต้แผนที่ ข้อความตรงทุกตัวอักษรกับ "แผนที่ประเทศไทยแบบหกเหลี่ยม: อ้างอิงรูปแบบจาก Hex Map of Thailand ผลงานของ ผศ. ดร. ภูริพันธุ์ รุจิขจร อาจารย์ประจำภาควิชาสถิติ จุฬาลงกรณ์มหาวิทยาลัย และผู้ร่วมก่อตั้ง Boonmee Lab" โดย "Hex Map of Thailand" เป็นลิงก์ไป github.com/puripant/thailand-hex-map และเปลี่ยนเป็น Kittapat Ratanaphupha เมื่อดูรายเขต; ภาพหัวหน้าพรรคสูง ≥ 70px บนการ์ดที่ยังสูงไม่ถึง 100px; หลังเลือกพรรค การ์ดเป็นออบเจ็กต์เดิม (ปรับในที่) การ์ดอื่น 9 ใบจาง และมีหกเหลี่ยมกำลังเปลี่ยนสี จากนั้นจบที่สีที่ถูกต้อง (กรุงเทพฯ #e8ecf1); เลือกเขตจากรายการแล้วมีวงกระเพื่อม; หน้าวิเคราะห์มีภาพเก่าซ้อนแล้วหายภายใน 0.8 วินาที จุดในกราฟกระจายยังครบ 400 ขนาดภาพวัดที่ 6 ขนาดจอ: การ์ด ชื่อ ตัวเลข ตำแหน่งเท่าเดิมทุกขนาด

## 4. Nested Model (vis-11 p.49–50)
| ชั้น | ภัยคุกคาม | การตรวจที่ทำ |
|---|---|---|
| Domain problem | เข้าใจผู้ใช้ผิด | กำหนดผู้ใช้หลักเป็นประชาชนทั่วไป ถอดฟังก์ชัน audit/OCR ที่ไม่ใช่งานของผู้ใช้กลุ่มนี้ (ยังไม่ได้ยืนยันกับผู้ใช้จริง) |

## 5. สิ่งที่ยังไม่ได้ตรวจ
