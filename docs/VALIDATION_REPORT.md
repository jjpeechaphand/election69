รอบเครดิต/ภาพ/การเคลื่อนไหว (3 พ.ย. 2569): e2e เพิ่มการตรวจ — เครดิตอยู่นอกกรอบแผนที่และใต้แผนที่ ข้อความตรงทุกตัวอักษรกับ "แผนที่ประเทศไทยแบบหกเหลี่ยม: อ้างอิงรูปแบบจาก Hex Map of Thailand ผลงานของ ผศ. ดร. ภูริพันธุ์ รุจิขจร อาจารย์ประจำภาควิชาสถิติ จุฬาลงกรณ์มหาวิทยาลัย และผู้ร่วมก่อตั้ง Boonmee Lab" โดย "Hex Map of Thailand" เป็นลิงก์ไป github.com/puripant/thailand-hex-map และเปลี่ยนเป็น Kittapat Ratanaphupha เมื่อดูรายเขต; ภาพหัวหน้าพรรคสูง ≥ 70px บนการ์ดที่ยังสูงไม่ถึง 100px; หลังเลือกพรรค การ์ดเป็นออบเจ็กต์เดิม (ปรับในที่) การ์ดอื่น 9 ใบจาง และมีหกเหลี่ยมกำลังเปลี่ยนสี จากนั้นจบที่สีที่ถูกต้อง (กรุงเทพฯ #e8ecf1); เลือกเขตจากรายการแล้วมีวงกระเพื่อม; หน้าวิเคราะห์มีภาพเก่าซ้อนแล้วหายภายใน 0.8 วินาที จุดในกราฟกระจายยังครบ 400 ขนาดภาพวัดที่ 6 ขนาดจอ: การ์ด ชื่อ ตัวเลข ตำแหน่งเท่าเดิมทุกขนาด

## 4. Nested Model (vis-11 p.49–50)
| ชั้น | ภัยคุกคาม | การตรวจที่ทำ |
|---|---|---|
| Domain problem | เข้าใจผู้ใช้ผิด | กำหนดผู้ใช้หลักเป็นประชาชนทั่วไป ถอดฟังก์ชัน audit/OCR ที่ไม่ใช่งานของผู้ใช้กลุ่มนี้ (ยังไม่ได้ยืนยันกับผู้ใช้จริง) |
| Task/data abstraction | ถามคำถามผิด | 4 คำถามหลัก + 3 คำถามรอง ผูกกับข้อมูลที่มีจริง ไม่สร้างตัวแปรที่ข้อมูลไม่รองรับ |
| Encoding/interaction | เลือกภาพผิด | เหตุผลแต่ละกราฟใน `VISUALIZATION_DESIGN.md`; มุมมองตารางคู่; ข้อความเตือนการตีความ |
| Algorithm | คำนวณผิด/ช้า | ชุดทดสอบตัวเลข 72 ข้อ, ตรวจภายใน 15 ข้อ, เทียบเว็บ กกต. สดต่าง 0 รายการ, สรุปคำนวณครั้งเดียวตอนโหลด |

## 5. สิ่งที่ยังไม่ได้ตรวจ
