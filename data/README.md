# ข้อมูลการเลือกตั้งที่หน้าเว็บใช้

แก้ไฟล์ CSV ในโฟลเดอร์นี้ด้วย Excel หรือ Google Sheets แล้วบันทึกเป็น **CSV UTF-8** หน้าเว็บจะแสดงข้อมูลใหม่เมื่อผู้ใช้กดปุ่มอัปเดต (ไอคอนลูกศรวนมุมขวาบน บนโทรศัพท์อยู่ในเมนูมุมซ้ายบน) หรือเปิดหน้าใหม่

- `elections.csv` รายการการเลือกตั้ง ตั้ง "แสดงบนเว็บ" = ใช่ ให้ครั้งที่ต้องการแสดง
- `2569/` หนึ่งโฟลเดอร์ต่อการเลือกตั้งหนึ่งครั้ง: election.csv (ทั่วไป) parties.csv (พรรค หัวหน้าพรรค แคนดิเดตนายกฯ ฝ่ายในสภา) provinces.csv (จังหวัด) constituencies.csv (เขต) candidates.csv (ผู้สมัครและคะแนน) party_list_votes.csv (คะแนนบัญชีรายชื่อ) sources.csv (แหล่งข้อมูล)
- `bundle.js` สร้างอัตโนมัติสำหรับเปิดหน้าเว็บจากไฟล์ในเครื่อง ห้ามแก้เอง หลังแก้ CSV ให้สั่ง `python -I -X utf8 scripts/build_data_bundle.py` (หรือดับเบิลคลิก build-data.bat) ซึ่งจะตรวจข้อมูลและสร้างไฟล์นี้ใหม่

ห้ามแก้ชื่อภาษาอังกฤษในวงเล็บของหัวคอลัมน์ ชื่อพรรคต้องตรงกันทุกไฟล์ ช่องว่าง = ยังไม่มีข้อมูล (ไม่ใช่ 0)

คู่มือฉบับเต็ม: `docs/DATA_EDITING_GUIDE.md`

## ฝ่ายในสภา (เพิ่ม 12 พ.ย. 2569)
`parties.csv` มีคอลัมน์สุดท้าย **ฝ่ายในสภา (house_side)**: `รัฐบาล` / `ฝ่ายค้าน` / คำอื่น เช่น `อิสระ` (ไม่อยู่ทั้งสองฝ่าย) / ว่าง และ `election.csv` มีค่า `house_checked_at` (วันที่ตรวจสอบ), `house_source_th`, `house_source_en`, `house_source_url`, `house_note_th`, `house_note_en` ใช้กับการ์ดฝ่ายรัฐบาล/ฝ่ายค้านในแท็บรวมเสียงตั้งรัฐบาล ไม่ใช่ผลเลือกตั้ง แก้ได้เมื่อการเมืองเปลี่ยน วิธีแก้อยู่ใน `docs/DATA_EDITING_GUIDE.md` ข้อ 3.5
